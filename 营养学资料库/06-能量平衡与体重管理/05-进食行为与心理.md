# 进食行为与心理

## 核心结论

进食行为受生理、情绪和环境共同影响：

1. **饥饿**是生理信号，**食欲**是想吃，**渴望**是特定食物的强烈冲动。
2. 长期严格限制会提高暴食风险，形成“节食—失控—自责—更严格节食”的循环。
3. 改变行为的关键是**降低触发、增加替代、建立规律**，而不是靠意志力硬扛。
4. 反复暴食、明显痛苦或影响生活，可能是进食障碍，需要专业帮助。

## 三个概念

| 概念 | 含义 | 例子 |
|---|---|---|
| 饥饿 | 身体需要能量的生理信号 | 胃空、乏力、注意力下降 |
| 食欲 | 想吃东西的欲望，不一定饿 | 看到美食想吃 |
| 渴望 | 对特定食物的强烈冲动 | 压力大时特别想吃甜食 |

情绪性进食通常不是饿，而是用食物调节情绪。识别触发点是第一步。

## 常见的进食模式

| 模式 | 特点 | 风险 |
|---|---|---|
| 情绪性进食 | 压力、焦虑、无聊时吃 | 热量过剩、自责 |
| 限制性进食 | 严格规则、黑白分明 | 暴食、社交回避 |
| 暴食 | 短时间大量进食、失去控制 | 肥胖、代谢问题、心理痛苦 |
| 夜食 | 夜间进食、早晨不饿 | 睡眠和代谢紊乱 |
| 无意识进食 | 看剧、刷手机时吃 | 份量失控 |

## 限制—暴食循环

1. 设定严格规则：“不能吃碳水/甜食”。
2. 一旦破戒，产生“全完了”的想法。
3. 干脆放开吃，出现暴食。
4. 自责，制定更严格的规则。
5. 循环加剧。

打破循环的方法：

- 取消“好食物/坏食物”的标签。
- 规律三餐，避免过度饥饿。
- 允许适量喜欢的食物，减少“禁果效应”。
- 一次吃多不等于失败，下一餐正常吃即可。

## 生理因素

| 因素 | 影响 |
|---|---|
| 睡眠不足 | 饥饿素升高、瘦素下降，更想吃高热量食物 |
| 蛋白质和纤维不足 | 饱腹感差，加餐增多 |
| 极端节食 | 身体提高食欲、降低消耗 |
| 压力 | 皮质醇升高，增加腹部脂肪和高糖食物偏好 |
| 药物 | 部分抗抑郁药、激素等增加食欲 |

## 行为改变工具

1. **自我监测**：记录吃了什么、什么时候、什么情绪，找出模式。
2. **刺激控制**：把零食收进不透明容器、不放在触手可及处。
3. **实施意图**：用“如果……就……”句式，例如“如果晚上想看剧，就先泡一杯无糖茶”。
4. **习惯叠加**：把新习惯接在旧习惯后，例如“吃完晚饭就散步 10 分钟”。
5. **预先承诺**：提前决定聚餐吃什么、喝什么。
6. **替代行为**：压力大时先散步、洗澡、打电话，而不是直接打开零食。
7. **认知重构**：把“我不能吃”换成“我可以选择吃，但我想先照顾目标”。

## 正念进食

- 用 1~10 分的饥饿量表，吃到 7~8 分饱。
- 放下手机，专注食物的味道和口感。
- 每口咀嚼 15~20 次，给饱腹信号时间。
- 吃之前问自己：我是饿了，还是累、烦、无聊？
- 不评判，只观察。

## 什么时候需要专业帮助

出现以下情况，建议寻求心理或营养专业支持：

1. 反复暴食，感到失控和明显痛苦。
2. 用催吐、泻药、过度运动补偿。
3. 体重快速下降、月经紊乱、怕冷、脱发。
4. 因饮食回避社交，或情绪被体重严重左右。
5. 夜间进食、秘密进食、囤积食物。

## 常见误区

1. **“管不住嘴就是意志力差”**：生理、情绪和环境的影响远大于意志力。
2. **“完全戒掉甜食就能解决”**：过度限制反而增加渴望和暴食。
3. **“暴食一次就前功尽弃”**：一顿饭不会决定长期结果，下一餐正常吃即可。
4. **“情绪性进食是道德问题”**：它是应对机制，可以用更健康的方式替代。
5. **“正念进食就是慢慢吃”**：核心是觉察饥饿、情绪和饱腹信号。

## 实操建议

1. 先记录 3 天进食和情绪，找出最常见的触发场景。
2. 规律三餐，蛋白质和纤维吃够，减少生理性饥饿。
3. 把高热量零食放在看不见、拿不到的地方。
4. 设定一个“如果—就”计划，替代情绪性进食。
5. 每周复盘一次，不追求完美，只求比上周好一点。
