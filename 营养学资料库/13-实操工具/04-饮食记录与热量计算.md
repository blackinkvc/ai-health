# 饮食记录与热量计算

## 核心结论

饮食记录的价值不在“算得准”，而在**让你看见自己实际吃了什么**：

1. 连续记录 3~7 天，包含工作日和周末。
2. 称重优先，外食用估算和拍照。
3. 别漏烹调油、酱料、饮料、零食和酒。
4. 用一周平均和体重趋势判断，不因单日偏差焦虑。

## 记录什么

| 项目 | 内容 |
|---|---|
| 时间 | 早餐、午餐、晚餐、加餐、夜宵 |
| 食物 | 所有食物和饮料，包括水 |
| 份量 | 克数、碗勺、手掌估算 |
| 做法 | 蒸、煮、炒、炸、烤，是否额外加油糖 |
| 地点/情绪 | 帮助发现触发场景 |
| 体重 | 每周 2~3 次，同一时间 |

## 记录方法

| 方法 | 优点 | 缺点 |
|---|---|---|
| 称重记录 | 最准确 | 麻烦，外食难 |
|  household measure | 方便 | 份量误差 |
| 拍照记录 | 快速、直观 | 难量化 |
| App 记录 | 自动算营养 | 数据库误差 |
| 纸质记录 | 不受干扰 | 需手动计算 |

建议：在家称重 + 外食拍照/估算，混合使用。

## 热量计算步骤

1. 查食物成分表或 App，确认是**每 100 克**还是**每份**。
2. 换算实际重量：生重/熟重、可食部。
3. 计算每种食物热量。
4. 加上烹调油、酱料、饮料。
5. 汇总全天，和 TDEE 对比。

示例：

- 米饭 150 克熟：约 174 千卡
- 鸡胸肉 100 克生：约 120 千卡
- 西兰花 200 克 + 10 克油：约 70 + 90 = 160 千卡
- 苹果 200 克：约 104 千卡
- 牛奶 250 毫升：约 150 千卡
- 合计：约 708 千卡（一餐）

## 常见误差

| 误差 | 对策 |
|---|---|
| 漏记油、酱、饮料 | 先记这些“隐形热量” |
| 生熟混用 | 称生重或使用熟食数据 |
| 份量估小 | 用标准碗勺、拍照 |
| 周末不记 | 周末往往是超标重点 |
| App 数据不准 | 核对品牌和做法 |
| 记录期间刻意少吃 | 记录真实饮食，不“表演” |

## 用记录做复盘

1. 看总热量是否接近目标。
2. 看蛋白质是否足够。
3. 看蔬菜、水果、奶、全谷物是否达标。
4. 看油、糖、酒、零食占多少。
5. 找出最容易超标的场景：外卖、聚餐、夜宵、压力。
6. 下周只改一个场景。

## 常见误区

1. **“记录必须精确到个位数”**：趋势比精确更重要。
2. **“App 算出来就是真实”**：数据库和份量都有误差。
3. **“只记正餐就行”**：零食和饮料常是热量大头。
4. **“记录几天没瘦就是没用”**：记录是工具，不是减重本身。
5. **“记录会让你焦虑”**：有进食障碍倾向者应避免过度量化，改用拍照或结构化饮食。

## 实操建议

1. 从记录 3 天开始，不要一上来就 30 天。
2. 先记饮料、零食、油和酱料。
3. 用同一套碗勺，建立份量感。
4. 每周固定一天复盘，写下一个改进点。
5. 达到目标后可以停止详细记录，保留每周称重和食物类别检查。
