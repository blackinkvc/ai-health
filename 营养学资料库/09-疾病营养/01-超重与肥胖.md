# 超重与肥胖

> 本文为一般营养原则，不能替代个体化医疗方案。肥胖合并糖尿病、高血压、肾病、进食障碍或正在用药者，请在医生/注册营养师指导下执行。

## 核心结论

肥胖是一种由遗传、环境、行为和心理共同作用的慢性疾病。

1. 评估不只看体重，还要看腰围、体脂和代谢并发症。
2. 减重 5%~10% 就能显著改善血压、血糖、血脂和脂肪肝。
3. 治疗核心是可持续的生活方式干预，必要时联合药物或手术。
4. 不追求快速减重，每周 0.5~1 公斤更可持续。

## 评估

| 指标 | 中国标准 |
|---|---|
| BMI | 18.5~23.9 正常；24~27.9 超重；≥28 肥胖 |
| 腰围 | 男性 ≥90 cm、女性 ≥85 cm 为中心型肥胖 |
| 体脂率 | 结合年龄、性别判断 |
| 并发症 | 糖尿病、高血压、血脂异常、脂肪肝、睡眠呼吸暂停、骨关节炎 |
| 心理 | 暴食、情绪性进食、抑郁、体重污名 |

## 医学营养治疗原则

1. **能量缺口**：每天 300~500 千卡，或 500~750 千卡（需专业监督）。
2. **蛋白质**：1.2~1.6 克/公斤，减重期保住肌肉。
3. **碳水**：优先全谷物、豆类、蔬果，限制添加糖和精制碳水。
4. **脂肪**：20%~30%，减少饱和脂肪和反式脂肪。
5. **纤维**：25~30 克，增加饱腹感。
6. **行为**：规律三餐、记录、控制份量、减少高热量食物暴露。

## 可选饮食模式

| 模式 | 特点 | 适用 |
|---|---|---|
| 均衡低热量 | 三大营养素比例合理 | 大多数人 |
| 地中海 | 蔬果、全谷、豆类、鱼、橄榄油 | 心血管风险人群 |
| DASH | 高钾高钙低钠 | 高血压人群 |
| 低碳水 | 控制精制碳水和糖 | 偏好低碳水、胰岛素抵抗者 |
| 间歇性断食 | 限制进食窗口 | 能耐受、习惯少餐者 |
| 代餐 | 短期替代 1~2 餐 | 需要明确份量者 |

在总热量和蛋白质相同的情况下，效果差异不大，依从性是关键。

## 药物与手术边界

- 生活方式干预 3~6 个月效果不佳，且达到指征，可在医生评估下考虑药物。
- 中国指南中，BMI ≥28 或 ≥24 合并并发症可评估药物；BMI ≥32.5 或 ≥27.5 合并并发症可评估手术。
- 药物和手术都必须配合饮食、运动和心理支持，不是“一劳永逸”。
- 任何减重药物都有副作用和禁忌症，不要自行购买或滥用。

## 常见误区

1. **“胖是因为懒/没意志力”**：肥胖受遗传、激素、环境、睡眠、药物和心理影响。
2. **“减得越快越好”**：快速减重更多流失肌肉和水分，反弹率更高。
3. **“局部减脂”**：脂肪动员是全身性的。
4. **“代餐可以长期替代正餐”**：不利于建立长期饮食习惯，也可能营养不均衡。
5. **“体重正常就不胖”**：瘦人也可能有内脏脂肪高、代谢异常。

## 实操建议

1. 先定 5%~10% 的阶段性目标，不要盯着“标准体重”。
2. 每餐先吃蔬菜和蛋白质，再吃主食。
3. 戒含糖饮料，减少外卖和油炸。
4. 每周 150~300 分钟有氧 + 2 次力量训练。
5. 保证睡眠 7~9 小时，管理压力。
6. 每 2 周复盘体重、腰围和饮食记录。
