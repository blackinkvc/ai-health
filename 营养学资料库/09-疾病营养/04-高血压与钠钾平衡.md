# 高血压与钠钾平衡

> 本文为一般营养原则，不能替代个体化医疗方案。血压 ≥180/120 mmHg 或伴胸痛、呼吸困难、意识改变，应立即就医。

## 核心结论

高血压的营养干预，证据最充分的是四件事：

1. **限钠**：食盐每天 <5 克。
2. **补钾**：多吃蔬菜、水果、豆类、薯类。
3. **减重**：体重每降 1 公斤，收缩压约降 1 mmHg。
4. **限酒**：酒精会升高血压。

DASH 饮食和限盐结合，降压效果更明显。

## 血压标准

| 场景 | 高血压诊断参考 |
|---|---|
| 诊室血压 | ≥140/90 mmHg |
| 家庭自测 | ≥135/85 mmHg |
| 动态血压白天 | ≥135/85 mmHg |

具体诊断和分级由医生判断，单次升高不等于高血压。

## 钠：主要来自加工食品

- 推荐食盐 <5 克/天，约相当于钠 2000 毫克。
- 我国居民钠摄入的主要来源：酱油、腌制品、加工肉、零食、外卖、餐馆菜。
- 不是“少放盐”就够了，还要看营养成分表的钠含量。
- 低钠盐用氯化钾替代部分氯化钠，但肾功能不全、服用保钾药物者慎用。

### 减钠技巧

1. 用限盐勺，逐步减少。
2. 用葱姜蒜、醋、柠檬、香草提味。
3. 少喝汤底、少蘸酱、少吃腌菜。
4. 买包装食品看钠含量，每 100 克低于 600 毫克较理想。
5. 外食要求少盐少酱，主食不泡汤汁。

## 钾：对抗钠的升压作用

- 成人钾适宜摄入量约 2000 毫克/天；WHO 建议提高到约 3500 毫克/天。
- 高钾食物：菠菜、土豆、红薯、香蕉、橙子、豆类、菌菇、低脂奶。
- 增加钾的同时减少钠，效果更好。
- 肾功能不全、服用 ACEI/ARB、保钾利尿剂者，补钾前必须咨询医生。

## 体重、运动与酒精

| 因素 | 建议 | 预期效果 |
|---|---|---|
| 体重 | 超重者减重 5%~10% | 收缩压约降 5~10 mmHg |
| 运动 | 每周 150 分钟中等强度 | 收缩压约降 4~9 mmHg |
| 酒精 | 尽量不喝 | 明显降低血压 |
| 吸烟 | 戒烟 | 降低心血管风险 |
| 睡眠 | 7~9 小时，筛查睡眠呼吸暂停 | 改善夜间血压 |

## DASH 饮食落地

- 每天蔬菜 4~5 份、水果 4~5 份。
- 低脂奶 2~3 份。
- 全谷物替代精制主食。
- 鱼禽替代红肉和加工肉。
- 坚果豆类每周 4~5 份。
- 甜食和含糖饮料尽量少。

## 常见误区

1. **“不咸就没有盐”**：加工食品、酱料、汤底含大量隐形钠。
2. **“低钠盐人人适合”**：高钾风险人群可能出事。
3. **“红酒能降血压”**：酒精总体升血压，不建议为健康喝酒。
4. **“芹菜汁/醋泡花生能降压”**：没有可靠证据，不能替代药物。
5. **“血压正常就可以停药”**：擅自停药可能导致反弹，需医生评估。

## 实操建议

1. 买个家用血压计，固定时间测量并记录。
2. 把盐降到 5 克以下，逐步适应。
3. 每天 500 克蔬菜、250 克水果、一份豆类或薯类。
4. 超重者减重，每周 150 分钟运动。
5. 限制酒精，保证睡眠，筛查打鼾和呼吸暂停。
6. 按医嘱服药和复查，不自行调整。
