# 肿瘤与肌少症

> 本文为一般营养原则，不能替代个体化医疗方案。肿瘤治疗期和肌少症干预需由肿瘤科、营养科和康复科共同管理。

## 核心结论

肿瘤患者最常见的营养问题是**营养不良和肌肉流失**，而不是“营养过剩”：

1. 能量 25~35 千卡/公斤，蛋白质 1.0~1.5 克/公斤，按耐受调整。
2. 定期筛查营养不良和体重下降。
3. 治疗期注意食品安全，避免生食。
4. 没有证据支持“饿死癌细胞”“碱性饮食”“大量补剂抗癌”。
5. 肌少症靠蛋白质 + 抗阻训练 + 维生素 D，单靠吃不够。

## 肿瘤营养原则

| 项目 | 建议 |
|---|---|
| 能量 | 25~35 千卡/公斤/天 |
| 蛋白质 | 1.0~1.5 克/公斤/天；恶病质可更高，需专业指导 |
| 碳水 | 保证足够能量，优先全谷物和蔬果 |
| 脂肪 | 适量，优先不饱和脂肪；omega-3 可能有助于炎症 |
| 纤维 | 按耐受，腹泻或梗阻时调整 |
| 水分 | 按需，呕吐腹泻时补充电解质 |
| 餐次 | 少量多餐，必要时口服营养补充 |

## 营养不良筛查

- 体重 1 个月内下降 >5%，或 6 个月内 >10%，需要评估。
- 使用 PG-SGA、MNA-SF 等工具筛查。
- 关注食欲、咀嚼吞咽、恶心呕吐、腹泻便秘、味觉改变。
- 及早转诊营养科，不要等到明显消瘦。

## 治疗期常见问题

| 问题 | 应对 |
|---|---|
| 食欲差 | 少量多餐、高能量高蛋白、餐前散步 |
| 恶心呕吐 | 清淡、少油、姜、避免强烈气味；按医嘱止吐 |
| 口腔溃疡 | 软烂、温凉、少酸辣；保持口腔卫生 |
| 味觉改变 | 用柠檬、香草、醋调味；尝试不同温度 |
| 腹泻 | 补水电解质、低纤维低脂、避免乳糖 |
| 便秘 | 增加水分和纤维，适量活动，必要时用药 |
| 吞咽困难 | 调整质地，必要时吞咽评估 |

## 食品安全

治疗期间免疫力可能下降，尤其白细胞低时：

1. 不吃生鱼、生肉、生蛋、未巴氏杀菌奶。
2. 水果去皮或彻底清洗。
3. 剩菜彻底复热，避免室温放置。
4. 生熟分开，砧板刀具分开。
5. 避免霉变、过期和来源不明的食物。

## 关于“抗癌饮食”

| 说法 | 真相 |
|---|---|
| 糖会“喂养”癌细胞 | 所有细胞都用葡萄糖，不吃糖不能饿死癌细胞，反而可能导致营养不良 |
| 碱性饮食能防癌 | 人体酸碱由缓冲系统调节，食物不能改变血液 pH |
| 断食能增强化疗 | 证据不足，可能加重营养不良，需医生评估 |
| 高蛋白会“喂肿瘤” | 蛋白质是维持肌肉和免疫的必需营养，不应盲目限制 |
| 大量补剂抗癌 | 多数证据不足，某些抗氧化剂可能干扰治疗 |

## 肌少症

肌少症是骨骼肌量、力量或功能下降，常见于老年人和慢性病患者。

### 筛查

- SARC-F 问卷
- 握力下降
- 步速变慢
- 从椅子站起困难
- 肌肉量减少（影像或人体成分）

### 干预

| 措施 | 建议 |
|---|---|
| 蛋白质 | 1.0~1.2 克/公斤，疾病期 1.2~1.5；每餐 25~30 克 |
| 亮氨酸 | 优质蛋白中丰富，乳清蛋白、蛋、鱼、瘦肉 |
| 抗阻训练 | 每周 2~3 次，渐进超负荷 |
| 维生素 D | 缺乏者补充，遵医嘱 |
| 能量 | 保证足够热量，避免体重下降 |
| 综合管理 | 治疗原发病、康复、预防跌倒 |

## 常见误区

1. **“肿瘤患者要忌口，不能吃鱼虾”**：除非过敏，优质蛋白很重要。
2. **“吃素能防癌”**：植物性饮食有益，但不等于纯素，也不治疗肿瘤。
3. **“补剂越多越好”**：可能干扰治疗，补充前问医生。
4. **“体重下降是治疗正常反应”**：需要评估和干预，不能忽视。
5. **“肌少症只能靠吃”**：必须结合抗阻训练。

## 实操建议

1. 每周称体重，记录下降趋势。
2. 每餐保证一个掌心蛋白质，少量多餐。
3. 治疗期严格注意食品安全。
4. 每周 2~3 次抗阻和平衡训练，量力而行。
5. 不自行采用极端饮食或大剂量补剂，先与肿瘤科团队沟通。
