# 血脂异常与心血管疾病

> 本文为一般营养原则，不能替代个体化医疗方案。是否使用降脂药物、目标值多少，必须由医生根据总体风险决定。

## 核心结论

- **LDL-C 是动脉粥样硬化的因果因素**，降低 LDL-C 可降低心血管事件风险。
- 饮食重点不是“完全不吃脂肪”，而是**用不饱和脂肪替代饱和脂肪**。
- 反式脂肪应尽量避免。
- 甘油三酯升高与精制碳水、糖、酒精和体重关系更密切。

## 血脂指标

| 指标 | 意义 |
|---|---|
| LDL-C | 坏胆固醇，动脉粥样硬化主要驱动因素 |
| HDL-C | 好胆固醇，过低与风险增加相关 |
| 甘油三酯 | 与饮食、酒精、胰岛素抵抗相关 |
| 总胆固醇 | LDL + HDL + 其他脂蛋白 |
| 非 HDL-C | 总胆固醇减 HDL，反映致动脉粥样硬化脂蛋白总量 |
| ApoB | 每个致动脉粥样硬化颗粒一个，部分指南更重视 |

## 饮食原则

| 项目 | 建议 |
|---|---|
| 饱和脂肪 | <总能量 7%~10% |
| 反式脂肪 | 尽量避免 |
| 不饱和脂肪 | 替代饱和脂肪，橄榄油、菜籽油、坚果、鱼 |
| 膳食纤维 | 25~30 克/天 |
| 可溶性纤维 | 5~10 克/天，燕麦、豆类、车前子 |
| 植物甾醇 | 2 克/天，可降低 LDL 约 7%~10% |
| 鱼 | 每周 2 次，其中 1 次深海鱼 |
| 钠 | <5 克盐/天 |
| 添加糖 | <总能量 10%，最好 <5% |

## 具体怎么吃

### 减少饱和脂肪

- 少吃肥肉、黄油、奶油、猪油、椰子油、棕榈油。
- 选瘦肉、去皮禽肉、低脂奶。
- 看标签，避免“部分氢化植物油”“植脂末”。

### 增加不饱和脂肪

- 用橄榄油、茶籽油、菜籽油替代部分动物油。
- 每天一小把原味坚果。
- 每周 2 次鱼。

### 增加可溶性纤维

- 燕麦、大麦、豆类、苹果、柑橘、车前子。
- 每天一碗燕麦或一份豆类，能提供可观的 β-葡聚糖和纤维。

### 植物甾醇

- 2 克/天可降低 LDL 约 7%~10%。
- 强化食品（植物甾醇黄油、酸奶）可考虑，但不能替代药物。
- 价格较高，优先保证整体饮食。

## 甘油三酯高怎么吃

1. 减少精制碳水、含糖饮料和甜食。
2. 限制酒精，尤其是啤酒和甜酒。
3. 减重，减少内脏脂肪。
4. 增加运动。
5. 每周 2 次鱼，补充 omega-3。
6. 必要时在医生指导下使用降甘油三酯药物。

## 证据

- 胆固醇治疗试验协作组（CTT）汇总分析：LDL-C 每降低 1 mmol/L，主要血管事件风险约降低 22%。
- 用不饱和脂肪替代饱和脂肪，可降低 LDL-C 和心血管风险。
- 可溶性纤维 5~10 克/天，LDL-C 约降低 5%。
- 植物甾醇 2 克/天，LDL-C 约降低 7%~10%。
- 地中海饮食和 DASH 饮食与心血管风险降低相关。

## 常见误区

1. **“鸡蛋胆固醇高，冠心病不能吃”**：多数人每天 1 个鸡蛋安全，高反应者个体化。
2. **“瘦人不会血脂高”**：瘦人也可能有遗传性高胆固醇或内脏脂肪高。
3. **“椰子油是健康油”**：椰子油饱和脂肪极高，会升高 LDL。
4. **“鱼油可以代替他汀”**：鱼油主要降甘油三酯，不能替代降 LDL 药物。
5. **“吃他汀伤肝，不如不吃”**：获益远大于风险，需按医嘱监测。

## 实操建议

1. 先做一次完整血脂谱，评估总体心血管风险。
2. 用不饱和油替代动物油，控制总油量 25~30 克。
3. 每天燕麦或豆类，保证可溶性纤维。
4. 每周 2 次鱼，少吃加工肉和油炸食品。
5. 超重者减重 5%~10%，每周 150 分钟运动。
6. 按医嘱复查血脂，不自行停药。
