# 糖尿病与胰岛素抵抗

> 本文为一般营养原则，不能替代个体化医疗方案。用药、胰岛素剂量和血糖目标必须由医生调整。

## 核心结论

糖尿病医学营养治疗的目标是：

1. 控制血糖和糖化血红蛋白（HbA1c）。
2. 维持或达到健康体重。
3. 控制血脂、血压，降低心血管风险。
4. 保证营养充足，维持生活质量。

没有“降糖食物”，关键是**总能量、碳水质量、进食结构和依从性**。

## 糖尿病类型

| 类型 | 特点 | 营养重点 |
|---|---|---|
| 1 型 | 胰岛素绝对缺乏 | 碳水计数、胰岛素匹配、防低血糖 |
| 2 型 | 胰岛素抵抗 + 分泌不足 | 减重、控碳水、改善胰岛素敏感性 |
| 妊娠糖尿病 | 孕期首次发现 | 碳水分配、监测、保证胎儿营养 |
| 其他特殊类型 | 胰腺疾病、药物等 | 针对病因 |

## 饮食原则

| 项目 | 建议 |
|---|---|
| 能量 | 按体重、活动量和目标个体化；超重者制造温和缺口 |
| 碳水 | 占总能量 45%~60% 或个体化；优先低 GI、高纤维 |
| 蛋白质 | 1.0~1.5 克/公斤；合并肾病者 0.8 克/公斤左右 |
| 脂肪 | 20%~30%，减少饱和脂肪和反式脂肪 |
| 纤维 | 25~30 克/天 |
| 盐 | <5 克/天 |
| 餐次 | 规律三餐，避免跳餐和暴食 |

## 碳水怎么选

| 优先 | 限制 |
|---|---|
| 全谷物、糙米、燕麦、荞麦 | 白米饭、白面包、精制面条 |
| 杂豆、薯类（替代部分主食） | 糕点、饼干、糖果 |
| 整果 | 果汁、含糖饮料 |
| 蔬菜 | 油炸淀粉类食物 |

- 碳水不是越少越好，重点是**总量和来源**。
- 低碳水饮食可作为一种选择，但需监测和个体化，尤其使用胰岛素者。
- 碳水计数对 1 型糖尿病和胰岛素使用者尤其重要。

## 进食顺序与餐盘

1. 先吃蔬菜，再吃蛋白质，最后吃主食。
2. 餐盘法：一半蔬菜、四分之一蛋白质、四分之一主食。
3. 细嚼慢咽，一餐至少 20 分钟。
4. 避免“只吃主食”的一餐，如一大碗面或粥配咸菜。

## 体重与胰岛素抵抗

- 超重者减重 5%~10% 可显著改善血糖和胰岛素敏感性。
- 内脏脂肪减少比体重数字更重要。
- 力量训练增加肌肉，有助于葡萄糖利用。
- 睡眠不足和压力会加重胰岛素抵抗。

## 低血糖处理

使用胰岛素或磺脲类药物者，出现心慌、出汗、手抖、饥饿、意识模糊时：

1. 立即测血糖（如可测）。
2. 吃 15 克快速碳水：半杯果汁、3~4 块方糖、1 汤匙蜂蜜。
3. 15 分钟后复测，仍低则重复。
4. 稳定后补充一份含蛋白质和碳水的小餐。
5. 严重低血糖或意识障碍，立即就医/呼叫急救，不要强行喂食。

## 常见误区

1. **“糖尿病不能吃水果”**：整果可以吃，注意份量和时间，避免果汁。
2. **“无糖食品可以随便吃”**：无糖不等于无碳水，很多仍高脂高热量。
3. **“苦瓜/秋葵能降糖治病”**：不能替代药物，证据不足。
4. **“主食越少越好”**：过度限制可能导致低血糖、乏力和依从性差。
5. **“打胰岛素就可以随便吃”**：胰岛素不能抵消长期过量热量。

## 实操建议

1. 固定三餐时间，避免跳餐。
2. 每餐先菜后肉再主食。
3. 主食一半换全谷物或杂豆。
4. 戒含糖饮料，水果选整果、分次吃。
5. 每周至少 150 分钟运动 + 2 次力量训练。
6. 定期监测血糖、HbA1c、血脂、血压和肾功能。
