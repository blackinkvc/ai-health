# 高尿酸与痛风

> 本文为一般营养原则，不能替代个体化医疗方案。急性发作期用药和降尿酸方案必须由医生决定。

## 核心结论

1. 血尿酸升高是痛风的基础，但只有部分高尿酸者会发作。
2. 饮食能降低尿酸约 10%~18%，多数人仍需药物才能达标。
3. 重点限制：动物内脏、部分海鲜、啤酒、果糖饮料。
4. 低脂奶、蔬菜、适量咖啡可能有助于降低风险。
5. 减重要缓慢，快速减重和生酮饮食可能诱发发作。

## 什么是高尿酸

- 尿酸是嘌呤代谢的终产物。
- 高尿酸血症通常指血尿酸超过约 420 微摩尔/升，具体诊断标准由医生判断。
- 尿酸过高可在关节形成尿酸盐结晶，引发痛风性关节炎。
- 痛风常累及大脚趾、踝、膝，表现为红、肿、热、痛。

## 饮食原则

| 食物 | 建议 |
|---|---|
| 动物内脏（肝、肾、脑） | 避免 |
| 浓肉汤、火锅汤 | 避免 |
| 沙丁鱼、凤尾鱼、贝类 | 限制 |
| 红肉、禽肉 | 适量，每餐掌心大小 |
| 啤酒、白酒 | 限制或避免 |
| 含糖饮料、果汁 | 避免 |
| 低脂奶、酸奶 | 鼓励 |
| 蔬菜、全谷物、豆类 | 鼓励（植物嘌呤影响小） |
| 水 | 每天 2~3 升，心肾功能不全者遵医嘱 |
| 咖啡 | 适量，与尿酸降低相关 |

## 关于嘌呤的常见误解

- 并非所有高嘌呤蔬菜都不能吃。蘑菇、菠菜、豆类的植物嘌呤与痛风发作关联较弱。
- 真正需要严格限制的是**动物内脏、浓肉汤、部分海鲜和啤酒**。
- 果糖会促进尿酸生成，含糖饮料和大量果汁是容易被忽视的风险。
- 酒精既增加尿酸生成，又减少排泄，啤酒还含嘌呤。

## 体重与生活方式

- 超重者减重有助于降低尿酸，但要**缓慢**，每周 0.5~1 公斤。
- 快速减重、断食、生酮饮食可能因酮体竞争排泄而升高尿酸。
- 规律运动，避免剧烈运动诱发急性发作。
- 保证饮水，避免脱水。
- 控制高血压、血脂和血糖，这些与高尿酸常并存。

## 急性发作期

1. 休息、抬高患肢、局部冷敷。
2. 及时就医，按医嘱使用抗炎止痛药。
3. 不要在发作期自行开始或停用降尿酸药，需医生指导。
4. 多喝水，避免酒精和高嘌呤食物。
5. 不要按摩或热敷关节。

## 降尿酸治疗

- 反复发作、痛风石、肾结石或尿酸明显升高者，通常需要长期降尿酸药物。
- 目标通常为血尿酸 <360 微摩尔/升，严重者 <300 微摩尔/升，具体由医生设定。
- 饮食和生活方式是辅助，不能替代药物。
- 开始降尿酸药时可能诱发发作，医生会安排预防用药。

## 常见误区

1. **“痛风不能吃豆腐”**：植物嘌呤影响较小，适量豆制品通常可以。
2. **“吃樱桃能治痛风”**：可能有轻微辅助作用，不能替代药物。
3. **“不喝啤酒，喝白酒没事”**：所有酒精都增加风险。
4. **“不痛就不用管尿酸”**：长期高尿酸损伤关节和肾脏。
5. **“严格忌口就能停药”**：多数人单靠饮食无法达标。

## 实操建议

1. 每天喝水 2~3 升，观察尿色。
2. 避免内脏、浓汤、啤酒和含糖饮料。
3. 红肉和海鲜控制份量，不集中大量摄入。
4. 每天低脂奶或酸奶，增加蔬菜和全谷物。
5. 超重者缓慢减重，避免断食和极端生酮。
6. 按医嘱复查尿酸，不自行停药。
