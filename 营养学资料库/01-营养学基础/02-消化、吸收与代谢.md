# 消化、吸收与代谢

## 核心结论

吃进去 ≠ 吸收，吸收 ≠ 利用。营养状况取决于**消化效率、吸收部位、食物基质和个体肠道状态**四件事。理解这条链路，才能解释为什么同样一份饭，不同人得到的营养并不相同。

## 关键概念

| 概念 | 解释 |
|---|---|
| 消化 | 把大分子食物分解成可吸收的小分子，包括机械、化学和微生物作用 |
| 吸收 | 小分子通过肠上皮进入血液或淋巴 |
| 代谢 | 吸收后的营养素在肝脏和全身细胞中被转化、储存或氧化供能 |
| 生物利用度 | 摄入量中真正被吸收并可用于生理功能的比例 |
| 食物基质 | 营养素在食物中的存在形式与伴随成分，会影响释放和吸收 |

## 消化道的分工

### 口腔

- 咀嚼把食物切碎，增加酶作用的表面积
- 唾液 α-淀粉酶开始水解淀粉，舌脂酶参与少量脂肪消化
- 唾液黏液起润滑作用，帮助吞咽

### 胃

- 胃酸把 pH 维持在约 1.5~3.5，激活胃蛋白酶原，杀灭部分微生物
- 胃蛋白酶开始蛋白质水解，胃脂肪酶参与脂肪消化
- 淀粉在胃内基本停止消化，因为胃酸使唾液淀粉酶失活
- 胃排空速度：液体约 1~2 小时，混合餐约 3~5 小时；脂肪、蛋白质和纤维会减慢排空

### 小肠

小肠是消化吸收的主战场，成人长约 5~7 米，靠绒毛和微绒毛把吸收面积扩大到约 200 平方米。

| 营养素 | 主要消化酶 / 部位 | 吸收方式 |
|---|---|---|
| 淀粉 | 胰淀粉酶 → 麦芽糖；刷状缘麦芽糖酶、蔗糖酶、乳糖酶 → 单糖 | 葡萄糖、半乳糖经 SGLT1（钠依赖）；果糖经 GLUT5 |
| 蛋白质 | 胃蛋白酶、胰蛋白酶、糜蛋白酶、羧肽酶；刷状缘肽酶 | 氨基酸和小肽经主动转运，小肽经 PepT1 |
| 脂肪 | 胆盐乳化；胰脂肪酶 → 2-单酰甘油 + 游离脂肪酸 | 形成混合微胶粒，进入肠上皮后重新酯化，经乳糜微粒入淋巴 |
| 铁 | 十二指肠 | 血红素铁吸收率高；非血红素铁受植酸、单宁抑制，维生素 C 促进 |
| 钙 | 十二指肠、空肠 | 维生素 D 依赖的主动转运 + 被动扩散 |
| 维生素 B12 | 回肠末端 | 需胃内因子协助 |
| 胆盐 | 回肠末端 | 肠肝循环，重复利用 |

中链脂肪酸不需要形成乳糜微粒，可直接经门静脉入肝，这也是中链甘油三酯（MCT）在特殊医学用途中被使用的原因。

### 大肠

- 吸收水分和电解质，把食糜变成粪便
- 肠道菌群发酵未消化的碳水（膳食纤维、抗性淀粉），产生短链脂肪酸（乙酸、丙酸、丁酸）
- 丁酸是结肠上皮的主要能源，对肠道屏障有重要意义

## 影响吸收的常见因素

| 因素 | 影响 |
|---|---|
| 植酸、草酸、单宁 | 与铁、钙、锌结合，降低吸收率 |
| 维生素 C | 促进非血红素铁吸收 |
| 烹饪 | 加热提高淀粉糊化度和蛋白质消化率，但会损失部分水溶性维生素 |
| 食物基质 | 整颗坚果、全谷物中的营养素被细胞壁包裹，吸收率低于精制食物 |
| 肠道疾病 | 炎症性肠病、乳糜泻、短肠综合征会显著影响吸收 |
| 药物 | 质子泵抑制剂影响 B12 和铁吸收；二甲双胍长期使用可致 B12 不足；奥利司他影响脂溶性维生素 |

## 常见误区

1. **“消化好就是吸收好”**：消化是分解，吸收是转运，两者可以脱节。
2. **“喝粥养胃”**：白粥容易消化，但营养密度低、升糖快，不等于“养胃”。
3. **“空腹不能吃某食物”**：多数说法缺乏证据，关键看总量和个人耐受。
4. **“食物相克”**：正常食材搭配不会产生毒性，真正风险是变质和卫生问题。
5. **“乳糖不耐受就永远不能喝奶”**：可选择无乳糖奶、酸奶或少量多次，多数人并非绝对禁忌。

## 实操建议

1. 细嚼慢咽，尤其对全谷物、豆类和肉类，能明显减轻胃肠负担。
2. 补铁餐避免同时喝浓茶、咖啡；搭配彩椒、猕猴桃等维生素 C 来源。
3. 增加纤维要循序渐进，同时保证饮水，否则可能加重便秘。
4. 乳糖不耐受者从少量酸奶或硬奶酪开始，观察个体耐受。
5. 长期服用抑酸药、二甲双胍或有胃肠道手术史的人，定期关注 B12、铁、钙和脂溶性维生素。
