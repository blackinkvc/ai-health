# 营养学概论

## 核心结论

营养学研究的不是“某种食物治什么病”，而是**食物、营养素与人体健康之间的剂量-效应关系**。它有三个基本立场：

1. **剂量决定作用**：缺乏会致病，过量同样有风险，安全区间比“越多越好”重要。
2. **整体膳食优于单一食物**：长期吃什么结构，比偶尔吃什么“超级食物”更能预测健康结局。
3. **证据会更新**：营养学是实验科学，不是传统经验的集合；结论要跟着证据走。

## 关键概念

| 概念 | 解释 | 常见误解 |
|---|---|---|
| 营养学 | 研究食物供给、摄取、消化吸收、代谢与健康效应的科学 | 等同于“食疗”或“养生” |
| 营养素 | 食物中能被人体利用、维持生命和健康的物质 | 只有维生素和矿物质才算营养 |
| 必需营养素 | 人体不能合成或合成不足，必须从食物获得 | 所有营养素都必须额外补充 |
| 膳食模式 | 长期形成的食物组合与比例 | 可以靠某一种食物替代整体饮食 |
| 营养状况 | 营养素摄入、吸收、利用与身体储备的综合状态 | 看体重就能判断营养好坏 |

### 学科分支

| 分支 | 研究重点 | 典型问题 |
|---|---|---|
| 基础营养学 | 营养素的代谢与生理功能 | 蛋白质如何被消化吸收 |
| 人群营养学 | 不同人群的摄入与需求 | 老年人需要多少蛋白质 |
| 临床营养学 | 疾病状态下的营养治疗 | 肾病患者怎么限蛋白 |
| 公共营养学 | 人群层面的政策与干预 | 如何降低居民钠摄入 |
| 食品营养学 | 加工对营养的影响 | 烹饪损失多少维生素 C |
| 运动营养学 | 运动与营养的配合 | 训练后怎么补蛋白 |

## 数据与证据

- 营养学成为独立学科，与 20 世纪维生素的发现密切相关：1912 年 Casimir Funk 提出“维生素”概念，此后陆续确认多种维生素与缺乏病的关系。
- 1940 年代起，各国开始制定膳食营养素推荐供给量，逐步发展为今天的 DRIs 体系。
- 中国先后发布 2000 年、2013 年、2023 年版膳食营养素参考摄入量；《中国居民膳食指南（2022）》是当前膳食实践的核心文件。
- 《中国居民营养与慢性病状况报告（2020 年）》显示，我国成年居民超重与肥胖合计已超过一半，同时部分微量营养素摄入不足仍然存在——这就是常说的“营养双重负担”。

这些数据说明：营养问题很少是“缺某一种神药”，更多是**结构失衡**——能量过剩与微量营养素不足并存。

## 常见误区

1. **“天然的就一定安全”**：毒蘑菇、生豆角、未煮熟的豆浆都天然，但有毒。
2. **“营养素越多越好”**：维生素 A、铁、硒等过量都有明确风险。
3. **“某种食物能治某病”**：食物不是药物，不能替代治疗；能降低风险不等于能治病。
4. **“传统说法一定科学”**：传统经验有价值，但需要现代证据验证，例如“骨头汤补钙”就不成立。
5. **“体重正常就营养良好”**：瘦人也可能缺铁、缺维生素 D 或蛋白质不足。

## 实操建议

1. 先看**整体膳食模式**：食物是否多样、比例是否合理、加工度是否过高。
2. 再找**高风险缺口**：奶类、深色蔬菜、全谷物、鱼虾往往是最容易不足的几类。
3. 用**一周平均**判断摄入，不要因为某一天没吃够就焦虑。
4. 遇到新说法，先问三个问题：剂量多少？研究对象是谁？证据是什么类型？
5. 有疾病、孕期哺乳期或正在服药，优先找医生或注册营养师，不用科普文章替代处方。
