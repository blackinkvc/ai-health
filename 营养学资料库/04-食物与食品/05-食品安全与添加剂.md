# 食品安全与添加剂

## 核心结论

食品安全的风险排序，和很多人的直觉相反：

1. **微生物污染**是急性食物中毒的头号原因。
2. 添加剂在合法剂量下经过风险评估，真正的问题是超范围、超量使用和营销误导。
3. 农药残留、重金属、霉菌毒素需要关注，但日常清洗、去皮、储存得当能显著降低风险。
4. 高温加工产生的丙烯酰胺、杂环胺、多环芳烃，是更值得注意的“自己制造的风险”。

## 三类主要危害

| 类型 | 例子 | 预防 |
|---|---|---|
| 生物性 | 沙门氏菌、大肠杆菌、金黄色葡萄球菌、李斯特菌、诺如病毒、寄生虫 | 彻底加热、生熟分开、冷藏 |
| 化学性 | 农药残留、重金属、霉菌毒素、非法添加物 | 清洗去皮、正规渠道、避免霉变 |
| 物理性 | 玻璃、金属、塑料碎片 | 正规包装、食用前检查 |

## 温度与时间：最有效的两个工具

| 场景 | 安全做法 |
|---|---|
| 冷藏 | 4℃ 以下 |
| 冷冻 | -18℃ 以下 |
| 危险温度带 | 5~60℃ 之间，细菌繁殖最快 |
| 熟食室温放置 | 不超过 2 小时；气温高于 32℃ 时不超过 1 小时 |
| 剩菜复热 | 中心温度 70℃ 以上 |
| 禽肉 | 中心温度 74℃ |
| 绞肉 | 中心温度 71℃ |
| 整块肉类 | 中心温度 63℃ 并静置 |
| 解冻 | 冷藏室、微波炉或冷水密封解冻，不在室温长时间放置 |

## 生熟分开

1. 准备生肉和熟食使用不同砧板、刀具。
2. 生肉汁液不要接触即食食品。
3. 处理生食后洗手，再接触熟食。
4. 冰箱里生肉放最下层，避免汁液滴落。
5. 抹布、海绵定期更换或消毒。

## 食品添加剂

### 常见类别

| 类别 | 作用 | 例子 |
|---|---|---|
| 防腐剂 | 抑制微生物 | 山梨酸钾、苯甲酸钠 |
| 抗氧化剂 | 防止油脂氧化 | 维生素 E、BHA、BHT |
| 着色剂 | 改善颜色 | 焦糖色、β-胡萝卜素 |
| 甜味剂 | 提供甜味 | 阿斯巴甜、三氯蔗糖、赤藓糖醇 |
| 增稠剂 | 改善质地 | 明胶、果胶、黄原胶 |
| 乳化剂 | 混合油水 | 卵磷脂、单双甘油脂肪酸酯 |
| 膨松剂 | 让面点松软 | 碳酸氢钠、明矾（限制铝） |
| 护色剂 | 保持肉色 | 亚硝酸盐（严格限量） |

### 怎么看添加剂

- 合法添加剂有**ADI（每日允许摄入量）**，按体重和终生摄入评估。
- “零添加”不等于更安全：没有防腐剂的食品可能更容易变质。
- 真正需要避开的是：非法添加物（如苏丹红、三聚氰胺）、超范围使用、以及高糖高油高盐的“添加剂堆砌”。
- 亚硝酸盐在肉制品中限量使用，主要风险来自高温煎烤产生的亚硝胺，而不是偶尔吃一次培根。

## 农药残留与清洗

1. 流水冲洗 30 秒以上，能去除大部分表面残留。
2. 叶菜掰开冲洗，瓜果去皮。
3. 焯水可进一步降低部分农药残留。
4. 不需要用洗洁精洗菜，清水足够。
5. 有机食品也会使用农药，只是限制不同，不能保证“零残留”。

## 霉菌毒素

- 发霉的花生、玉米、坚果可能含黄曲霉毒素，耐高温，普通烹饪无法破坏。
- 不要挑掉霉点继续吃，毒素可能已扩散。
- 粮食、坚果密封干燥保存，避免受潮。
- 苦味花生、变色大米直接丢弃。

## 高温加工产物

| 物质 | 来源 | 建议 |
|---|---|---|
| 丙烯酰胺 | 油炸/烘烤淀粉类 | 避免焦黄，控制温度 |
| 杂环胺 | 高温煎烤肉类 | 腌制、避免焦糊 |
| 多环芳烃 | 明火烧烤、烟熏 | 避免直接接触火焰 |
| 亚硝胺 | 腌制肉 + 高温 | 少吃加工肉，不高温煎烤 |

## 常见误区

1. **“添加剂都是有害的”**：合法添加剂经过评估，风险在于滥用而非“有”本身。
2. **“零添加一定更安全”**：没有防腐剂可能更容易滋生细菌。
3. **“有机食品没有农药”**：有机农业允许使用部分天然农药，也可能有环境残留。
4. **“隔夜菜一定致癌”**：冷藏得当的隔夜菜风险可控，真正风险是细菌污染。
5. **“食物相克会中毒”**：正常食材搭配不会产生毒性，卫生问题才是关键。

## 实操建议

1. 买菜回家先分装：生肉冷冻、蔬菜冷藏、干货密封。
2. 砧板分生熟，至少两块；用完洗净晾干。
3. 剩菜趁热密封冷藏，1~2 天内吃完，复热到 70℃ 以上。
4. 少吃过期、胀袋、霉变、异味食品。
5. 外食选卫生条件好的店，少吃生食和长时间室温放置的凉菜。
