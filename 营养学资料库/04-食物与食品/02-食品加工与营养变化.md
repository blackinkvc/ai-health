# 食品加工与营养变化

## 核心结论

“加工”是一个很宽的概念，不能一棍子打死：

1. 冷冻、冷藏、罐装、巴氏杀菌、发酵，能延长保质期、提高安全性，部分还改善营养。
2. 精制、油炸、反复高温、部分氢化，会损失营养或产生有害物质。
3. 真正与健康风险相关的是**超加工食品**：高油、高糖、高盐、低纤维、强适口性。

## NOVA 四类加工分级

| 级别 | 定义 | 例子 | 营养特点 |
|---|---|---|---|
| 第一类 | 未加工或最低限度加工 | 新鲜蔬果、生肉、鱼、蛋、原粮、豆类 | 保留天然结构 |
| 第二类 | 加工烹饪原料 | 食用油、盐、糖、醋、淀粉 | 少量使用，用于调味 |
| 第三类 | 加工食品 | 罐头、腌菜、面包、奶酪、熏肉 | 第一类 + 第二类加工而成 |
| 第四类 | 超加工食品 | 含糖饮料、薯片、饼干、速食面、香肠、代餐棒 | 工业配方，含添加剂，高适口性 |

NOVA 不是法规标准，而是一个研究分类。它的价值在于提醒：**同样的热量，超加工食品更容易吃过量**。

## 加工对营养的影响

| 加工方式 | 营养变化 | 建议 |
|---|---|---|
| 精制谷物 | 损失麸皮和胚芽，纤维、B 族维生素、矿物质下降 | 一半主食换全谷物 |
| 冷冻 | 快速冷冻可较好保留维生素，尤其是蔬菜 | 冷冻蔬菜是不错的备选 |
| 罐装 | 高温杀菌损失部分水溶性维生素，但矿物质和纤维保留 | 选低盐、无糖罐头 |
| 发酵 | 微生物合成 B 族维生素，分解部分抗营养因子 | 酸奶、豆豉、泡菜适量 |
| 腌制 | 高盐，维生素 C 损失 | 少量，注意钠 |
| 油炸 | 吸油、热量翻倍，维生素损失，可能产生丙烯酰胺 | 少油炸，避免复炸 |
| 烘烤 | 维生素损失中等，可能产生丙烯酰胺和 AGEs | 控制温度，避免焦糊 |
| 部分氢化 | 产生反式脂肪 | 避免“部分氢化植物油” |
| 强化 | 添加铁、钙、维生素等 | 强化面粉、加碘盐有益 |

## 超加工食品为什么容易吃过量

1. **能量密度高**：油、糖、精制淀粉组合，少量就高热量。
2. **适口性强**：口感、风味经过设计，容易触发奖励系统。
3. **纤维和蛋白质少**：饱腹感弱，吃得快、吃得多。
4. **份量包装大**：大包装和“买一送一”促进过量。
5. **液体热量**：含糖饮料不带来饱腹感。

观察性研究显示，超加工食品摄入比例较高与肥胖、心血管疾病、2 型糖尿病和部分癌症风险相关。这些研究存在混杂因素，但方向一致，足以支持“少吃”的建议。

## 加工并不都是坏事

- **巴氏杀菌和灭菌**：杀灭致病菌，保证牛奶安全。
- **冷冻蔬菜**：采摘后快速冷冻，维生素保留可能优于长途运输的“新鲜”蔬菜。
- **罐头豆类**：方便、纤维和蛋白质保留，选低盐版即可。
- **发酵食品**：酸奶、纳豆、豆豉提供蛋白质和部分益生菌。
- **强化食品**：加碘盐预防碘缺乏，强化面粉补充 B 族维生素。

## 如何识别超加工食品

1. 配料表很长，含多种添加剂、香精、色素、乳化剂。
2. 出现“部分氢化植物油”“植脂末”“高果糖玉米糖浆”。
3. 包装上强调“零脂肪”“无蔗糖”“高纤维”，但配料表前几位是糖或精制淀粉。
4. 开袋即食、保质期很长、常温保存的零食和速食。
5. 无法想象它在厨房里怎么做出来。

## 常见误区

1. **“加工食品都有毒”**：冷冻、罐装、巴氏杀菌是食品安全的重要保障。
2. **“新鲜一定比冷冻好”**：长途运输的“新鲜”蔬菜，维生素可能不如速冻蔬菜。
3. **“零添加更安全”**：没有防腐剂的食品也可能因微生物繁殖更危险。
4. **“非油炸就没有油”**：烘焙薯片、果蔬脆片仍可能高脂。
5. **“代餐棒很健康”**：很多是超加工食品，糖和油不少，蛋白质有限。

## 实操建议

1. 以第一、第二类食物为主，第三类适量，第四类尽量少。
2. 购物时优先买“原材料”，少买“开袋即食”。
3. 看配料表：前三位是糖、油、精制淀粉的，放回去。
4. 家里常备冷冻蔬菜、低盐罐头豆类，作为忙碌时的备选。
5. 不追求“零加工”，追求“少超加工、多完整食物”。
