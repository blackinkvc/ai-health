# 烹饪与营养保留

## 核心结论

烹饪是一把双刃剑：

1. 加热能提高淀粉糊化度、蛋白质消化率，并杀灭致病菌。
2. 但水溶性维生素怕水、怕热、怕光，长时间高温会明显损失。
3. 高温焦糊和油炸会产生丙烯酰胺、杂环胺、多环芳烃等有害物质。
4. **蒸、快炒、微波**通常比长时间水煮和油炸更能保留营养。

## 不同烹饪方式的营养保留

| 方式 | 维生素保留 | 优点 | 注意 |
|---|---|---|---|
| 蒸 | 较高 | 不接触大量水，受热均匀 | 时间别过长 |
| 微波 | 较高 | 加热快，水溶性维生素损失少 | 用微波炉专用容器 |
| 快炒 | 中等偏高 | 时间短，口感好 | 油温别过高，少油 |
| 焯水 | 中等 | 去除草酸、农药残留 | 水开后再下锅，时间短 |
| 长时间水煮 | 较低 | 软烂易消化 | 维生素溶入汤中，连汤吃 |
| 油炸 | 较低 | 口感好 | 吸油、热量高，可能产生有害物 |
| 明火烧烤 | 中等 | 风味强 | 避免焦糊，减少杂环胺和多环芳烃 |
| 烘烤 | 中等 | 适合肉类和根茎类 | 控制温度，避免焦黑 |

## 各类营养素的变化

### 水溶性维生素

- 维生素 C、B1、B2、叶酸最容易损失。
- 损失途径：溶于水、热破坏、氧化、光照。
- 对策：先洗后切、急火快炒、少水、盖锅盖、现做现吃。

### 脂溶性维生素

- 维生素 A、D、E、K 相对耐热，但长时间高温和氧化仍会损失。
- 胡萝卜素需要少量油脂帮助吸收，但不必大量用油。

### 蛋白质

- 加热使蛋白质变性，通常**提高**消化率。
- 但高温焦糊会产生杂环胺（HCA）和多环芳烃（PAH），增加癌症风险。
- 肉类提前用柠檬汁、醋、香料腌制，可减少 HCA 形成。

### 脂肪

- 高温会氧化脂肪，产生醛、酮等氧化产物。
- 反复使用的煎炸油会产生反式脂肪和极性化合物。
- 油冒烟说明已超过烟点，应避免。

### 矿物质

- 矿物质不会因加热“消失”，但会溶入煮菜水。
- 连汤吃、少弃汤，能减少损失。

## 常见有害产物

| 物质 | 来源 | 降低方法 |
|---|---|---|
| 丙烯酰胺 | 高温油炸/烘烤淀粉类（薯条、油条、烤面包） | 避免焦黄、控制温度、先焯水 |
| 杂环胺（HCA） | 高温煎烤肉类 | 避免焦糊、腌制、缩短时间 |
| 多环芳烃（PAH） | 明火烧烤、烟熏 | 避免直接接触火焰、去皮 |
| 晚期糖基化终产物（AGEs） | 高温干热、焦糖化 | 少油炸、少焦糖、多用蒸煮 |
| 反式脂肪 | 反复高温油炸、部分氢化油 | 不重复用油、看标签 |

## 实用烹饪技巧

1. **先洗后切**：切后再洗会流失水溶性维生素。
2. **水开下菜**：缩短焯水时间，减少维生素损失。
3. **急火快炒**：时间短、加水少，保留口感营养。
4. **善用蒸和微波**：尤其适合蔬菜和鱼。
5. **少油低温**：油温控制在冒烟点以下，避免反复煎炸。
6. **加点酸**：柠檬汁、醋可减少维生素氧化，也能降低 HCA。
7. **避免焦糊**：烤面包、煎肉时去掉焦黑部分。
8. **连汤吃**：炖菜、煮菜的汤里有溶出的维生素和矿物质。

## 常见误区

1. **“生吃一定更健康”**：豆角、豆浆、鸡蛋、肉类必须彻底加热。
2. **“微波炉破坏营养”**：微波加热时间短，水溶性维生素损失通常低于长时间水煮。
3. **“油冒烟才香”**：冒烟说明油温过高，会产生有害物质。
4. **“橄榄油不能加热”**：精炼橄榄油适合中温烹饪，初榨橄榄油适合凉拌和中低温。
5. **“焦香才好吃”**：焦糊部分含丙烯酰胺和 HCA，应避免。

## 实操建议

1. 蔬菜优先蒸、快炒、微波，少长时间水煮。
2. 肉类先腌制，再中低温煎烤，避免明火直烤和焦糊。
3. 煎炸油不重复使用，油冒烟就换。
4. 薯条、油条等淀粉类油炸食品少吃，家庭制作先焯水再炸可降低丙烯酰胺。
5. 每餐保证一份生鲜蔬果，弥补烹饪损失。
