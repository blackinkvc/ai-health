# 谣言识别方法论

## 核心结论

营养谣言有固定套路，识别它们不需要成为专家，只需要问对问题：

1. 剂量是多少？
2. 研究对象是谁？
3. 是什么研究类型？
4. 效应有多大？
5. 谁在从中获利？

## 十个常见逻辑漏洞

| 漏洞 | 表现 | 纠正 |
|---|---|---|
| 单一研究 | “一项研究发现……” | 看系统评价和重复验证 |
| 动物/体外实验 | 小鼠或细胞有效 | 不能直接推到人 |
| 相关当因果 | 吃某食物的人更瘦 | 可能是其他生活方式差异 |
| 剂量偷换 | 高剂量提取物有效 | 日常食用量远达不到 |
| 断章取义 | 只引用有利段落 | 看全文和作者结论 |
| 轶事证据 | “我邻居吃了就好了” | 个例不能证明效果 |
| 权威崇拜 | “专家说”“诺奖技术” | 看证据，不看头衔 |
| 天然谬误 | “天然所以安全” | 毒蘑菇也天然 |
| 阴谋论 | “医生不想让你知道” | 医疗建议受监管和证据约束 |
| 单一食物 | “吃它就能降血糖/抗癌” | 没有一种食物能解决复杂疾病 |

## 危险信号

1. 承诺“根治”“治愈”“替代药物”。
2. 强调“秘方”“内部消息”“被隐瞒的真相”。
3. 只用前后对比图、患者见证。
4. 没有具体剂量、研究出处或作者。
5. 制造恐惧：“吃错一口就致癌”。
6. 限时优惠、会销、拉人头。
7. 要求停用医生开的药。
8. 用“排毒”“碱性体质”“激活细胞”等模糊概念。

## 五步核查

### 第一步：找原始来源

- 文章有没有链接到论文、指南或官方机构？
- 论文是否存在？作者、期刊、年份是否可查？
- 注意 AI 生成的虚假引用，查 DOI 和期刊官网。

### 第二步：看研究类型

- 体外/动物：只能提示机制。
- 横断面：只能说明相关。
- 队列：看长期关联，但仍有混杂。
- RCT：因果证据更强。
- 系统评价/Meta：汇总证据，但看质量。

### 第三步：看剂量和人群

- 实验中用了多少剂量？日常能吃到的量是多少？
- 研究对象是健康人、患者、老年人还是运动员？
- 结果能否外推到你和家人？

### 第四步：看效应大小

- 相对风险降低 50%，绝对风险可能只从 2% 降到 1%。
- 替代指标（血脂、血糖）改善，不等于心血管事件减少。
- 统计显著不等于临床重要。

### 第五步：看利益冲突

- 研究是否由相关企业资助？
- 作者是否有专利、股权或顾问费？
- 传播者是否在卖产品？

## 常见话术拆解

| 话术 | 问题 |
|---|---|
| “哈佛研究证明” | 哪个研究？谁做的？发表在哪？ |
| “古人早就知道” | 传统经验需要现代证据验证 |
| “西药有毒，食物安全” | 食物也有毒性和相互作用 |
| “排出毒素，一身轻松” | “毒素”没有定义，排毒器官是肝肾 |
| “酸性体质致癌” | 人体酸碱由缓冲系统调节，食物不能改变血液 pH |
| “超级食物” | 营销词，没有统一定义 |

## 实操建议

1. 看到惊人结论，先停 10 秒，不要立刻转发。
2. 搜索“主题 + 系统评价/指南/辟谣”。
3. 查原始论文的样本量、随访时间和结局。
4. 问“如果这是真的，为什么指南没更新？”
5. 对卖产品的博主保持更高警惕。

## 常见误区

1. **“有论文就可靠”**： Predatory journals 和低质量研究很多。
2. **“专家说的都对”**：专家也可能有利益冲突或超出专业范围。
3. **“大家都说就是真的”**：流行不等于证据。
4. **“科学会变，所以不可信”**：科学是逐步修正，不是随意翻烧饼。
5. **“我吃了有效就是真的”**：安慰剂、回归均值和同时改变的其他因素都可能起作用。
