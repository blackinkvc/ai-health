# 中国居民膳食指南（2022）

## 核心结论

《中国居民膳食指南（2022）》是中国营养学会发布的权威膳食指导文件，核心可以压缩成三句话：

1. **食物多样，合理搭配**：每天 12 种以上，每周 25 种以上。
2. **吃动平衡，健康体重**：吃进去的和消耗掉的长期平衡。
3. **少盐少油，控糖限酒**：慢病风险主要来自“过量”。

它不要求每餐精确称重，而是给出一个可长期执行的比例框架。

## 八条准则

| # | 准则 | 关键动作 |
|---|---|---|
| 1 | 食物多样，合理搭配 | 谷薯、蔬果、蛋白、奶豆、油脂都要有 |
| 2 | 吃动平衡，健康体重 | 每周 150 分钟中等强度运动，每天主动活动 6000 步 |
| 3 | 多吃蔬果、奶类、全谷、大豆 | 蔬菜 300~500 克，水果 200~350 克，奶 300~500 毫升 |
| 4 | 适量吃鱼、禽、蛋、瘦肉 | 每天 1 个蛋，鱼禽瘦肉总量 120~200 克 |
| 5 | 少盐少油，控糖限酒 | 盐 <5 克，油 25~30 克，添加糖 <25 克 |
| 6 | 规律进餐，足量饮水 | 三餐规律，饮水 1500~1700 毫升 |
| 7 | 会烹会选，会看标签 | 多看配料表和营养成分表 |
| 8 | 公筷分餐，杜绝浪费 | 卫生、份量控制、减少浪费 |

## 平衡膳食宝塔（成人每日）

| 层级 | 食物 | 建议量 |
|---|---|---|
| 底层 | 谷类 | 200~300 克，其中全谷物和杂豆 50~150 克 |
| 底层 | 薯类 | 50~100 克 |
| 第二层 | 蔬菜 | 300~500 克，深色占一半 |
| 第二层 | 水果 | 200~350 克 |
| 第三层 | 畜禽肉 | 40~75 克 |
| 第三层 | 水产品 | 40~75 克 |
| 第三层 | 蛋类 | 40~50 克（约 1 个） |
| 第四层 | 奶及奶制品 | 300~500 克 |
| 第四层 | 大豆及坚果 | 25~35 克 |
| 顶层 | 烹调油 | 25~30 克 |
| 顶层 | 盐 | <5 克 |
| 其他 | 水 | 1500~1700 毫升 |

这些是**成人平均目标**，孕期、哺乳期、儿童、老年人和慢病人群需要调整。

## 体重与腰围

| 指标 | 中国标准 |
|---|---|
| BMI | 18.5~23.9 为正常；24~27.9 超重；≥28 肥胖 |
| 腰围 | 男性 <85 cm、女性 <80 cm 更理想；男性 ≥90 cm、女性 ≥85 cm 为中心型肥胖 |
| 运动 | 每周至少 150 分钟中等强度，或 75 分钟高强度 |

体重不是唯一指标，腰围和体脂更能反映腹部脂肪风险。

## 东方健康膳食模式

指南特别提到以浙江、上海、江苏等地为代表的“东方健康膳食模式”，特点是：

- 清淡少盐
- 食物多样
- 蔬菜、水果、豆制品丰富
- 鱼虾水产较多
- 奶类天天有
- 适量禽肉，红肉不过量

它比单纯照搬地中海饮食更适合中国饮食文化。

## 一日落地示例

| 餐次 | 内容 |
|---|---|
| 早餐 | 燕麦粥 + 1 个鸡蛋 + 1 杯牛奶 + 一小把坚果 |
| 午餐 | 杂粮饭 + 清蒸鱼 + 炒青菜 + 豆腐汤 |
| 加餐 | 一个苹果或一份无糖酸奶 |
| 晚餐 | 红薯 + 鸡胸肉/虾 + 一大盘蔬菜 |
| 全天 | 油 25~30 克，盐 <5 克，水 1500~1700 毫升 |

## 常见误区

1. **“指南是给病人看的”**：指南面向健康人群，慢病人群需要在此基础上个体化调整。
2. **“每天必须凑够 12 种食物”**：是长期平均目标，不必每餐精确计算。
3. **“宝塔是固定食谱”**：它是比例框架，同类食物可以互换。
4. **“只要吃够蔬菜就健康”**：蛋白质、全谷物、奶类同样重要。
5. **“少油就是无油”**：必需脂肪酸需要适量油脂，关键是控制在 25~30 克。

## 实操建议

1. 先改一件事：把一半主食换成全谷物或薯类。
2. 每餐先保证蔬菜和蛋白质，再考虑主食份量。
3. 用限盐勺和油壶，把“少盐少油”变成可见的数字。
4. 每周安排 2 次鱼，1 次动物血或肝脏。
5. 购物时按宝塔层级检查购物车，缺哪类补哪类。
