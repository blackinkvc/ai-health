# 地中海饮食

## 核心结论

地中海饮食不是某一份食谱，而是一种**以植物性食物为基础、用不饱和脂肪替代饱和脂肪**的膳食模式。

1. 每天：蔬菜、水果、全谷物、豆类、坚果、橄榄油。
2. 每周：鱼和海鲜至少 2 次，禽肉、蛋、奶适量。
3. 少量：红肉、加工肉、甜食、精制谷物。
4. 证据最强的是**心血管疾病风险降低**，而不是“包治百病”。

## 膳食结构

| 频率 | 食物 | 说明 |
|---|---|---|
| 每餐 | 蔬菜、水果、全谷物、豆类、坚果、橄榄油 | 占餐盘大部分 |
| 每周 2 次以上 | 鱼和海鲜 | 提供 omega-3 |
| 每周适量 | 禽肉、蛋、酸奶/奶酪 | 蛋白质来源 |
| 每月少量 | 红肉、甜食、加工肉 | 控制频率和份量 |
| 可选 | 红酒 | 仅限有饮酒习惯者，不饮酒者不建议开始 |

## 关键食物与作用

| 食物 | 关键营养 | 作用 |
|---|---|---|
| 橄榄油 | 单不饱和脂肪、多酚 | 替代黄油/猪油，改善血脂 |
| 蔬菜水果 | 钾、维生素 C、叶酸、纤维、多酚 | 抗氧化、降压、肠道健康 |
| 全谷物 | 纤维、B 族维生素、镁 | 平缓血糖、降低心血管风险 |
| 豆类 | 植物蛋白、纤维、钾 | 替代部分红肉 |
| 坚果 | 不饱和脂肪、维生素 E、镁 | 改善血脂，增加饱腹感 |
| 深海鱼 | EPA/DHA | 降低甘油三酯、抗炎 |
| 酸奶/奶酪 | 钙、蛋白质 | 适量，优先低脂或无糖 |

## 证据

- **PREDIMED 试验**：地中海饮食 + 特级初榨橄榄油或坚果，与对照饮食相比，主要心血管事件风险降低约 30%。
- 观察性研究显示，依从性越高，全因死亡、心血管疾病和部分癌症风险越低。
- 机制包括改善血脂、血压、炎症、胰岛素敏感性和肠道菌群。
- 局限性：地中海饮食的定义不统一，观察性研究存在混杂因素，试验对照组的饮食也并非“典型西方饮食”。

## 如何适配中国饮食

| 地中海元素 | 中国化替代 |
|---|---|
| 橄榄油 | 茶籽油、菜籽油、亚麻籽油（凉拌） |
| 全麦面包 | 糙米、燕麦、全麦馒头、玉米 |
| 奶酪 | 无糖酸奶、豆腐 |
| 深海鱼 | 三文鱼、鲭鱼、鲈鱼、带鱼 |
| 鹰嘴豆 | 黄豆、黑豆、红豆 |
| 坚果 | 核桃、杏仁、腰果（原味） |
| 香草 | 葱姜蒜、花椒、八角、香菜 |

不必追求“进口食材”，核心是**植物性食物为主、少红肉、用好油、常吃鱼**。

## 一日示例

| 餐次 | 内容 |
|---|---|
| 早餐 | 燕麦 + 无糖酸奶 + 蓝莓 + 核桃 |
| 午餐 | 糙米饭 + 清蒸鲈鱼 + 西兰花 + 番茄豆腐汤 |
| 加餐 | 一个橙子或一小把杏仁 |
| 晚餐 | 全麦面包 + 鸡胸肉沙拉 + 橄榄油醋汁 |
| 全天 | 蔬菜 500 克，水果 250 克，橄榄油/茶籽油 25~30 克 |

## 常见误区

1. **“地中海饮食就是意大利面和红酒”**：精制意面和过量酒精都不在推荐范围内。
2. **“橄榄油可以无限量”**：橄榄油仍是油，1 克 9 千卡，过量照样增重。
3. **“必须买进口食材”**：本地蔬菜、豆类、鱼类和茶籽油同样符合模式。
4. **“红酒保护心脏”**：证据不一致，不饮酒的人不应为了健康开始喝酒。
5. **“吃了橄榄油就不用管总热量”**：膳食模式不能突破能量平衡。

## 实操建议

1. 把家里的部分烹调油换成茶籽油或橄榄油，控制总量 25~30 克。
2. 每餐至少两份蔬菜，一份水果。
3. 每周吃 2 次鱼，1 次豆类主菜。
4. 红肉每周不超过 2 次，加工肉尽量不吃。
5. 用坚果替代饼干、薯片作为加餐。
