# 儿童与青少年

## 核心结论

这一阶段的营养目标是**支持生长发育**，而不是简单“控制体重”：

1. 能量和蛋白质要够，尤其是生长突增期。
2. 钙、铁、锌、维生素 D 是重点，关系到骨骼、血液和免疫。
3. 规律三餐、吃早餐、少含糖饮料，比吃补剂更重要。
4. 超重儿童不建议自行节食，应在家庭支持下调整结构和增加运动。

## 生长阶段

| 阶段 | 特点 | 营养重点 |
|---|---|---|
| 学龄前（3~6 岁） | 生长速度放缓，食欲波动 | 多样化、规律进餐、控制零食 |
| 学龄期（6~12 岁） | 稳定生长，学习任务增加 | 早餐、蛋白质、钙、铁 |
| 青春期（女 10~14，男 12~16） | 生长突增，性发育 | 能量、蛋白质、钙、铁、锌 |

## 每日食物框架

| 食物 | 建议量（学龄期） | 说明 |
|---|---|---|
| 谷类 | 150~300 克 | 全谷物和杂豆占一部分 |
| 薯类 | 25~50 克 | 可替代部分主食 |
| 蔬菜 | 300~500 克 | 深色占一半 |
| 水果 | 200~350 克 | 整果，不喝果汁 |
| 畜禽肉 | 50~75 克 | 瘦肉为主 |
| 鱼虾 | 50~75 克 | 每周 2 次 |
| 蛋类 | 1 个 | 不弃蛋黄 |
| 奶及奶制品 | 300~500 毫升 | 纯奶或无糖酸奶 |
| 大豆坚果 | 15~25 克 | 坚果需注意窒息风险 |
| 烹调油 | 20~25 克 | 少油炸 |
| 盐 | <4 克 | 越淡越好 |

具体数值随年龄、性别和活动量调整，青春期需求明显增加。

## 关键营养素

| 营养素 | 作用 | 来源 |
|---|---|---|
| 蛋白质 | 生长、肌肉、免疫 | 蛋、奶、鱼、禽、瘦肉、豆 |
| 钙 | 骨骼峰值骨量 | 奶、豆腐、绿叶菜、小鱼 |
| 铁 | 造血、认知 | 红肉、动物血、肝脏、豆类 |
| 锌 | 生长、免疫、味觉 | 牡蛎、牛肉、坚果、全谷物 |
| 维生素 D | 钙吸收、骨骼 | 日晒、强化奶、补充剂 |
| 膳食纤维 | 肠道、饱腹 | 全谷物、蔬果、豆类 |

青春期女孩是缺铁高风险人群，月经开始后尤其要关注。

## 早餐

- 不吃早餐与注意力下降、午餐过量、超重风险相关。
- 合格早餐应包含：主食 + 蛋白质 + 蔬果/奶。
- 示例：全麦面包 + 鸡蛋 + 牛奶 + 苹果；燕麦 + 酸奶 + 香蕉 + 坚果。
- 避免只吃糕点、饼干或含糖饮料。

## 零食与饮料

| 推荐 | 限制 |
|---|---|
| 水果、无糖酸奶、原味坚果、全麦面包 | 薯片、饼干、糖果、蛋糕 |
| 白水、纯牛奶 | 含糖饮料、奶茶、果汁饮料 |

- 含糖饮料是儿童肥胖和龋齿的重要来源。
- 果汁不能替代水果，1~3 岁每天不超过 120 毫升，尽量不给。
- 零食安排在两餐之间，不影响正餐。

## 运动与睡眠

| 项目 | 建议 |
|---|---|
| 运动 | 每天至少 60 分钟中高强度活动 |
| 屏幕时间 | 非学习用途每天不超过 2 小时 |
| 睡眠 | 学龄儿童 9~11 小时，青少年 8~10 小时 |

## 超重与肥胖

- 用年龄性别对应的 BMI 百分位判断，不用成人标准。
- 家庭共同调整：减少含糖饮料、增加蔬果和蛋白质、控制份量、增加运动。
- 不建议儿童自行节食或使用代餐。
- 严重肥胖或合并代谢问题，转诊儿科或营养专科。

## 挑食与偏食

1. 家长决定“吃什么、什么时候吃”，孩子决定“吃多少”。
2. 新食物重复暴露 8~15 次，不强迫。
3. 不用甜食作为奖励，避免把食物和情绪绑定。
4. 让孩子参与买菜和做饭，提高接受度。
5. 家长以身作则，家庭一起吃同样的食物。

## 常见误区

1. **“孩子胖点有福气”**：儿童肥胖增加成年肥胖和代谢病风险。
2. **“长身体要多补”**：优先食物，盲目补剂可能过量。
3. **“儿童食品更健康”**：很多“儿童食品”高糖高盐，看标签更重要。
4. **“喝奶就够了”**：奶不能提供铁和全部营养，需要多样食物。
5. **“吃糖会让孩子多动”**：证据不足，但糖确实增加龋齿和热量。

## 实操建议

1. 每天保证早餐，包含主食、蛋白质和奶/水果。
2. 每天 300~500 毫升奶，1 个鸡蛋，1~2 份水果。
3. 含糖饮料换成白水，果汁不替代水果。
4. 每天至少 60 分钟活动，周末安排户外。
5. 定期记录身高体重，看生长曲线而不是单次数字。
