# 成年期营养

## 核心结论

18~64 岁是慢病风险逐渐累积的阶段，营养重点从“长身体”转为“维持和预防”：

1. 维持能量平衡，避免逐年增重。
2. 保证蛋白质，保住肌肉，尤其久坐人群。
3. 膳食纤维、钙、铁、维生素 D 是常见缺口。
4. 外食、酒精、含糖饮料和久坐是主要风险来源。

## 每日框架

| 食物 | 建议 |
|---|---|
| 谷类 | 200~300 克，全谷物和杂豆 50~150 克 |
| 薯类 | 50~100 克 |
| 蔬菜 | 300~500 克，深色占一半 |
| 水果 | 200~350 克 |
| 畜禽肉 | 40~75 克 |
| 水产品 | 40~75 克 |
| 蛋类 | 1 个 |
| 奶及奶制品 | 300~500 毫升 |
| 大豆坚果 | 25~35 克 |
| 烹调油 | 25~30 克 |
| 盐 | <5 克 |
| 水 | 1500~1700 毫升 |

## 关键营养素

| 营养素 | 成年期关注点 |
|---|---|
| 蛋白质 | 1.0~1.2 克/公斤，减重和健身期更高 |
| 膳食纤维 | 25~30 克，改善血脂、血糖和肠道 |
| 钙 | 800 毫克，50 岁以上 1000 毫克 |
| 铁 | 育龄女性 18 毫克，男性 12 毫克 |
| 维生素 D | 400 IU，日晒不足者检测后补充 |
| 维生素 B12 | 长期素食、老年人、服用二甲双胍者关注 |
| 钾 | 多吃蔬果豆类，帮助控制血压 |

## 外食怎么选

1. 优先蒸、煮、炖、白灼，少油炸、干锅、红烧。
2. 主食减半，先吃蔬菜和蛋白质。
3. 酱料分开装，蘸着吃。
4. 少喝汤底和含糖饮料。
5. 聚餐前先吃一份蔬菜或酸奶，避免暴食。
6. 酒精尽量不喝，喝了就减少主食和油脂。

## 久坐与运动

| 问题 | 对策 |
|---|---|
| 久坐 | 每 60 分钟起身活动 3~5 分钟 |
| 活动不足 | 每周 150 分钟中等强度 + 2 次力量训练 |
| 颈肩腰背痛 | 调整工位，加入拉伸和核心训练 |
| 体重逐年上升 | 记录体重，及时调整 100~200 千卡 |

## 常见营养缺口

- 奶类不足 → 钙和蛋白质不足
- 蔬菜水果不足 → 钾、维生素 C、叶酸、纤维不足
- 全谷物不足 → 纤维和 B 族维生素不足
- 鱼虾不足 → omega-3 不足
- 日晒不足 → 维生素 D 不足
- 育龄女性 → 铁不足

## 健康筛查

| 项目 | 频率 |
|---|---|
| 体重、腰围、BMI | 每 3~6 个月 |
| 血压 | 每年至少 1 次 |
| 血脂 | 每 3~5 年，40 岁后更频繁 |
| 空腹血糖/糖化血红蛋白 | 每 3 年，高危人群每年 |
| 血常规 | 育龄女性、素食者定期 |
| 维生素 D | 高风险人群检测 |

## 常见误区

1. **“成年人不需要太多蛋白质”**：久坐和减重人群反而容易不足。
2. **“不吃晚饭能减肥”**：总热量和可持续性更重要，跳过晚餐可能导致暴食。
3. **“咖啡可以代替睡眠”**：咖啡因掩盖疲劳，不替代恢复。
4. **“补剂能弥补糟糕饮食”**：补剂是补充，不是替代。
5. **“瘦就没有代谢风险”**：瘦人也可能血脂、血糖异常，尤其内脏脂肪高者。

## 实操建议

1. 每餐一个掌心蛋白质，早餐也要有。
2. 每天 500 克蔬菜、250 克水果，尽量有深色。
3. 主食一半换全谷物或薯类。
4. 每天 300 毫升奶，每周 2 次鱼。
5. 控制酒精和含糖饮料，保证睡眠和运动。
