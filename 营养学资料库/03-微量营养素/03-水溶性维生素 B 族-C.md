# 水溶性维生素 B 族/C

## 核心结论

水溶性维生素在体内储备少，需要**每天从食物中补充**。它们的关键词是“辅助”：

1. B 族是能量代谢和造血的辅酶，不提供能量，不缺就没有“提神”效果。
2. 叶酸和 B12 共同参与红细胞生成，缺乏都会导致巨幼细胞性贫血。
3. 维生素 C 促进胶原合成和非血红素铁吸收，但大剂量补充没有额外益处。
4. 水溶性不等于绝对安全，B6、烟酸、维生素 C 过量都有明确风险。

## B 族维生素速查

| 维生素 | 主要功能 | 主要来源 | 缺乏表现 | 成人参考摄入 |
|---|---|---|---|---|
| B1 硫胺素 | 碳水代谢、神经传导 | 全谷物、猪肉、豆类、坚果 | 脚气病、Wernicke 脑病 | 男 1.4 / 女 1.2 毫克 |
| B2 核黄素 | 氧化还原反应、能量代谢 | 奶、蛋、肝脏、绿叶菜 | 口角炎、舌炎、脂溢性皮炎 | 男 1.4 / 女 1.2 毫克 |

| B6 吡哆醇 | 氨基酸代谢、血红素合成 | 禽肉、鱼、土豆、香蕉 | 贫血、周围神经病 | 约 1.4 毫克（UL 60 毫克） |

| B12 钴胺素 | 神经髓鞘、红细胞生成 | 动物性食物、强化食品 | 巨幼细胞性贫血、神经病变 | 2.4 微克 |

## 重点说明

### B1：酒精和精制主食是两大风险

- 长期大量饮酒会降低 B1 吸收并增加消耗，严重时可致 Wernicke 脑病。
- 长期以精制米面为主、缺乏全谷物和豆类，也可能摄入不足。
- 淘米过度、加碱煮粥会损失 B1。

### B2：奶类和蛋类是稳定来源

- 我国居民 B2 摄入不足较常见，尤其是不喝奶、少吃蛋的人。
- 光照会破坏 B2，牛奶应避光保存。

### B3：注意“烟酸当量”

- 色氨酸可转化为烟酸，因此用烟酸当量（NE）计量。
- 大剂量烟酸补充剂可致潮红、肝损伤，必须在医生指导下使用。
- 玉米为主的饮食若加工不当，可能因烟酸结合态导致癞皮病。

### B6：高剂量反而伤神经

- 长期大剂量补充（超过 UL 60 毫克/天）可导致周围神经病变。
- 正常饮食几乎不会过量，风险主要来自补充剂。

### B7：生蛋清与检测干扰

- 生蛋清中的抗生物素蛋白会结合生物素，长期大量食用可致缺乏。
- 高剂量生物素会干扰甲状腺、心肌酶等免疫检测，抽血前应告知医生是否服用。

### B9：备孕关键期

- 神经管在胚胎早期闭合，叶酸补充应从**备孕前至少 1 个月**开始。
- 备孕和孕早期通常建议每天补充 400 微克叶酸，具体遵医嘱。
- 绿叶菜、豆类、柑橘类水果是食物来源，但烹调损失较大。

### B12：素食者和老年人重点

- 几乎只存在于动物性食物中，严格素食者必须选择强化食品或补充剂。
- 老年人胃酸减少、胃内因子不足，吸收率下降。
- 长期服用二甲双胍、质子泵抑制剂，或有胃肠道手术史，风险增加。
- 缺乏可导致贫血和不可逆的神经损伤，早期识别很重要。

## 维生素 C

### 功能

- 胶原蛋白羟化，维持皮肤、血管、牙龈健康
- 促进非血红素铁吸收
- 抗氧化，保护细胞免受氧化损伤
- 参与神经递质和肉碱合成

### 来源与摄入

- 来源：新鲜蔬菜和水果，如彩椒、猕猴桃、柑橘、草莓、西兰花。
- 成人 RNI 约 100 毫克/天，UL 约 2000 毫克/天。
- 一只中等大小的猕猴桃或半个彩椒即可满足一天需求。

### 缺乏与过量

- 缺乏可致坏血病：牙龈出血、皮下瘀斑、伤口愈合差。
- 大剂量补充可引起腹泻、腹胀，增加草酸钙肾结石风险（易感人群）。
- “大剂量维生素 C 预防感冒”证据有限，仅在极端体力消耗人群中可能小幅缩短病程。

## 烹饪与保存

1. 水溶性维生素怕水、怕热、怕光、怕碱。
2. 蔬菜先洗后切，急火快炒，减少浸泡时间。
3. 焯水时水开后再下锅，缩短时间，焯菜水不要反复使用。
4. 水果现切现吃，避免长时间暴露在空气中。
5. 淘米次数不宜过多，煮粥不加碱。

## 常见误区

1. **“B 族能提神”**：只有缺乏时补充才有改善，不提供能量。
2. **“维生素 C 越多越好”**：超过 UL 没有额外收益，还可能增加结石风险。
3. **“素食者不会缺 B12”**：严格素食者风险最高，必须主动补充。
4. **“叶酸食物吃够就不用补”**：备孕和孕早期通常需要补充剂，遵医嘱。
5. **“果汁能补维生素 C”**：榨汁损失维生素 C 和纤维，整果更好。

## 实操建议

1. 主食加入全谷物和豆类，保证 B1、B3、B9。
2. 每天一份奶、一个蛋，补充 B2 和 B12。
3. 每天 300~500 克蔬菜、200~350 克水果，深色占一半。
4. 备孕前开始补充叶酸；素食者和老年人定期评估 B12。
5. 补充剂不要多种叠加，注意 B6、烟酸和维生素 C 的 UL。
