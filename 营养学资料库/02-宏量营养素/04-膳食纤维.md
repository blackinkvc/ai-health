# 膳食纤维

## 核心结论

膳食纤维是**不能被小肠消化吸收的碳水化合物**，但能被大肠菌群部分发酵，产生短链脂肪酸。它的价值不在“有营养”，而在调节肠道、血糖、血脂和饱腹感。

1. 目标：每天 25~30 克。
2. 来源：全谷物、杂豆、蔬菜、水果、坚果，而不是果汁。
3. 增加速度：每周逐步加量，同时多喝水，否则容易腹胀。

## 分类

| 类型 | 代表 | 主要作用 |
|---|---|---|
| 可溶性 / 黏性纤维 | 果胶、β-葡聚糖、树胶、车前子 | 延缓胃排空、降低胆固醇、平缓血糖 |
| 不可溶性 / 膨松纤维 | 纤维素、半纤维素、木质素 | 增加粪便体积、缩短肠道通过时间 |
| 抗性淀粉 | 冷米饭、冷土豆、青香蕉 | 不被小肠消化，发酵产生丁酸 |
| 益生元纤维 | 菊粉、低聚果糖、低聚半乳糖 | 选择性促进有益菌生长 |

多数天然食物同时含多种纤维，不必刻意区分“只吃可溶性”或“只吃不可溶性”。

## 健康作用与证据

| 作用 | 证据强度 | 说明 |
|---|---|---|
| 改善便秘 | 较强 | 增加粪便体积和水分，缩短传输时间 |
| 降低 LDL 胆固醇 | 较强 | β-葡聚糖、车前子等黏性纤维结合胆酸 |
| 平缓餐后血糖 | 中等 | 延缓胃排空和葡萄糖吸收 |
| 增加饱腹感 | 中等 | 体积、咀嚼时间和发酵产物共同作用 |
| 改善肠道菌群 | 中等 | 发酵产生短链脂肪酸，滋养结肠上皮 |
| 降低结直肠癌风险 | 中等 | 全谷物和膳食纤维摄入较高者风险较低 |

## 推荐量与食物来源

| 食物 | 纤维（约/100 克） |
|---|---|
| 燕麦片 | 10 |
| 黑豆（干） | 15~25 |
| 全麦面包 | 6~8 |
| 糙米（熟） | 1.8 |
| 西兰花 | 2.6 |
| 苹果（带皮） | 2.4 |
| 梨（带皮） | 3.1 |
| 杏仁 | 12.5 |
| 奇亚籽 | 34 |

一日示例：50 克燕麦（约 5 克）+ 一碗杂豆饭（约 6 克）+ 500 克蔬菜（约 10 克）+ 一个苹果（约 3 克）+ 一小把坚果（约 2 克），大约 26 克。

## 怎么增加纤维而不难受

1. **循序渐进**：每周增加 5 克左右，给肠道菌群适应时间。
2. **同时补水**：纤维需要吸水，饮水不足反而加重便秘。
3. **多样化**：不同纤维喂养不同菌群，不要只靠一种补充剂。
4. **烹饪软化**：老人和胃肠敏感者可把杂豆煮软、蔬菜做熟。
5. **记录反应**：腹胀明显时减量，优先保留蔬菜和全谷物，暂时减少豆类。

## 常见误区

1. **“喝果汁能补纤维”**：榨汁滤渣后纤维几乎损失殆尽，吃整果才有。
2. **“纤维越多越好”**：过量会腹胀、影响矿物质吸收，极少数人还会肠梗阻。
3. **“纤维补充剂可以替代蔬菜”**：补充剂只提供单一纤维，缺少维生素、矿物质和植物化学物。
4. **“粗粮一定比细粮纤维高”**：取决于配方，很多“粗粮饼干”纤维不高、油糖不少。
5. **“便秘就猛吃纤维”**：饮水不足、动力不足或出口梗阻时，猛加纤维可能更胀。

## 需要谨慎的人群

- 肠梗阻、严重肠狭窄、炎症性肠病急性期
- 刚做完胃肠道手术
- 严重腹胀、肠易激综合征（可短期尝试低 FODMAP，需专业指导）
- 老年人咀嚼和吞咽困难者，选择煮软的蔬菜、燕麦和豆泥

## 实操建议

1. 主食一半换全谷物或杂豆，先从燕麦、糙米开始。
2. 每天蔬菜 300~500 克，深色占一半；水果 200~350 克，吃整果。
3. 每天一小把原味坚果，约 10~15 克。
4. 增加纤维时把饮水提到 1500~2000 毫升。
5. 便秘持续超过 3 周、便血或体重下降，及时就医，不要只靠纤维。
