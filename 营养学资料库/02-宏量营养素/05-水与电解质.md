# 水与电解质

## 核心结论

水参与体温调节、营养运输、代谢反应和废物排出。**渴了再喝往往已经偏晚**，尤其老年人和运动人群。

1. 成人每天饮水约 1500~1700 毫升，食物中的水另算。
2. 食盐每天不超过 5 克，重点减少加工食品中的“隐形盐”。
3. 补钾优先靠蔬菜、水果、豆类和薯类，而不是补剂。
4. 长时间高强度运动才需要运动饮料，日常喝水即可。

## 水的分布与平衡

- 成年男性体内水分约占体重 60%，女性约 50%~55%，脂肪越多比例越低。
- 每日摄入：饮水 1500~1700 毫升 + 食物水 + 代谢水。
- 每日排出：尿液 1000~2000 毫升、皮肤蒸发约 500 毫升、呼吸约 300~400 毫升、粪便约 100~200 毫升。

### 水平衡的调节

- 下丘脑渗透压感受器感知血液浓度变化
- 抗利尿激素（ADH）调节肾脏重吸收水分
- 口渴感和肾脏浓缩尿液共同维持平衡
- 老年人渴感迟钝、肾脏浓缩能力下降，更容易脱水

## 电解质的作用

| 电解质 | 主要功能 | 主要来源 |
|---|---|---|
| 钠 | 维持细胞外液容量、神经传导、肌肉收缩 | 食盐、酱油、加工食品 |
| 钾 | 维持细胞内液、心跳节律、血压调节 | 蔬菜、水果、豆类、薯类、奶 |
| 氯 | 与钠共同维持渗透压和胃酸 | 食盐 |
| 钙 | 骨骼、肌肉收缩、凝血 | 奶制品、豆制品、绿叶菜 |
| 镁 | 酶反应、神经肌肉兴奋性 | 全谷物、坚果、绿叶菜 |
| 磷 | 骨骼、能量代谢 | 肉、蛋、奶、加工食品 |

## 钠与钾：血压的两端

### 钠

- 推荐食盐每天不超过 5 克，约相当于钠 2000 毫克。
- 我国居民钠摄入的主要来源不是盐罐，而是酱油、腌制品、加工肉、零食、外卖和餐馆菜。
- 减钠建议：看营养成分表的钠含量，少喝汤底，少用复合调味料。

### 钾

- 成人钾适宜摄入量约 2000 毫克/天；WHO 建议提高到约 3500 毫克/天以帮助降低血压。
- 高钾食物：菠菜、土豆、红薯、香蕉、橙子、豆类、菌菇、低钠盐。
- 肾功能不全者补钾需谨慎，可能出现高钾血症。

## 怎么判断是否缺水

| 指标 | 参考 |
|---|---|
| 尿液颜色 | 淡黄色较理想；深黄提示可能缺水 |
| 口渴感 | 出现口渴时已轻度缺水 |
| 体重变化 | 运动前后体重每下降 1 公斤，约需补液 1~1.5 升 |
| 头晕、乏力、便秘 | 可能是慢性轻度脱水的表现 |

## 运动补水

1. 运动前 2 小时喝 400~600 毫升水。
2. 运动中每 15~20 分钟少量多次，每次 150~250 毫升。
3. 运动超过 60~90 分钟且强度较高、出汗多时，可考虑含电解质的运动饮料。
4. 运动后按体重损失补液，每丢失 1 公斤补 1~1.5 升。
5. 大量出汗只补白水、不补钠，长时间耐力运动有低钠血症风险。

## 常见误区

1. **“每天必须喝 8 杯水”**：杯的大小、饮食结构、气候和活动量都不同，按需调整。
2. **“咖啡和茶会脱水”**：适量咖啡因饮料仍能补水，不会显著造成负平衡。
3. **“碱性水能调节体质”**：人体酸碱由缓冲系统精密调节，不靠饮水改变。
4. **“多喝水能排毒”**：肾脏和肝脏负责代谢废物，过量饮水反而增加低钠风险。
5. **“运动必须喝运动饮料”**：日常短时运动喝水足够，运动饮料含糖，可能带来额外热量。

## 特殊人群

| 人群 | 注意点 |
|---|---|
| 老年人 | 渴感迟钝，定时喝水；观察尿色 |
| 儿童 | 按体重和活动量补水，避免含糖饮料 |
| 孕妇/哺乳期 | 需求量增加，哺乳期尤其注意 |
| 高温作业者 | 补水和电解质同时进行 |
| 心衰、肾病、肝硬化 | 可能需要限水，严格遵医嘱 |

## 实操建议

1. 桌上放水杯，设定固定喝水时间点，不要等渴。
2. 用带刻度水壶，直观看到每天喝了多少。
3. 用葱姜蒜、醋、柠檬、香草替代部分盐和酱油。
4. 每天安排高钾食物：一份深色蔬菜 + 一份水果 + 一份豆类或薯类。
5. 运动前后称体重，按损失量补液，避免一次猛灌。
