# 食物环境与可持续饮食

## 核心结论

吃什么不只是个人选择，还受**食物环境**影响：

1. 价格、可获得性、广告、份量、货架位置都会影响购买。
2. 超加工食品和高糖饮料的营销，增加了过量摄入。
3. 可持续饮食与健康饮食有大量重叠：植物为主、多样化、减少浪费。
4. 不需要完美，改变购物和备餐习惯就能产生明显影响。

## 食物环境是什么

| 维度 | 例子 |
|---|---|
| 可获得性 | 社区有没有新鲜蔬果店 |
| 价格 | 健康食物是否更贵 |
| 营销 | 广告、促销、直播带货 |
| 份量 | 大包装、超大杯 |
| 信息 | 标签、营养声称、菜单标识 |
| 便利性 | 外卖、预制菜、即食食品 |
| 文化 | 家庭习惯、节日饮食 |

“食物沙漠”指新鲜食物难以获得的地区；“食物沼泽”指高热量低营养食品过度集中的环境。

## 超加工食品与环境

- 超加工食品能量密度高、适口性强、价格相对便宜。
- 大份量、买一送一、货架端头陈列，都会促进过量购买。
- 含糖饮料是最典型的“液体热量”，不带来饱腹感。
- 广告和网红推荐会放大消费。

## 可持续饮食

可持续饮食强调：

1. **健康**：满足营养需求，降低慢病风险。
2. **环境**：减少温室气体、土地和水资源消耗。
3. **社会**：可负担、文化可接受、公平。
4. **经济**：食物系统可持续。

### 共同方向

- 以植物性食物为主：蔬菜、水果、全谷物、豆类、坚果。
- 适量动物性食物，优先鱼禽，减少红肉和加工肉。
- 减少超加工食品和食物浪费。
- 选择当季、本地食材作为加分项，但不是唯一标准。
- 保证营养充足，尤其是蛋白质、铁、钙、B12、omega-3。

## 可持续不等于素食

- 纯素饮食如果计划不当，可能缺乏 B12、铁、钙、omega-3。
- 可持续饮食可以是弹性素食：以植物为主，少量鱼禽蛋奶。
- 关键是整体模式，而不是是否完全不吃肉。
- 不同地区的资源、文化和营养需求不同，不能一刀切。

## 食物浪费

全球约三分之一食物被浪费。家庭可以：

1. 制定一周菜单，按需采购。
2. 先吃易坏食材，剩余食材冷冻或做成汤。
3. 利用剩菜做炒饭、汤、沙拉。
4. 正确储存：叶菜冷藏、根茎阴凉、坚果密封。
5. 接受“丑蔬果”，不影响营养。
6. 外食按需点菜，打包剩菜。

## 政策与个人

| 层面 | 例子 |
|---|---|
| 政策 | 含糖饮料税、包装正面标签、限制儿童广告 |
| 社区 | 学校餐、菜市场、社区花园 |
| 家庭 | 采购、备餐、份量控制 |
| 个人 | 选择、烹饪、减少浪费 |

个人行动有意义，但不需要把系统性问题全部归咎于个人意志。

## 常见误区

1. **“可持续饮食很贵”**：豆类、全谷物、当季蔬果通常比加工食品便宜。
2. **“本地一定更环保”**：运输只是排放的一部分，生产方式更重要。
3. **“纯素自动可持续”**：超加工素食也可能高糖高脂，且需注意营养。
4. **“有机才可持续”**：有机是生产方式之一，不代表整体可持续。
5. **“个人改变没用”**：家庭采购和饮食习惯的累积影响很大。

## 实操建议

1. 每周安排 2~3 次豆类主菜，替代部分红肉。
2. 购物前列清单，按菜单买，减少浪费。
3. 优先当季蔬果，冷冻蔬菜也是好选择。
4. 少买超加工零食，把水果、坚果放在可见处。
5. 剩菜改造成新菜，避免直接丢弃。
6. 外食按需点餐，打包剩余。
