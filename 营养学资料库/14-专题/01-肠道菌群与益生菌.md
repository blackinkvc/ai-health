# 肠道菌群与益生菌

## 核心结论

肠道菌群与免疫、代谢和肠道屏障有关，但“调菌群”不是万能钥匙：

1. 饮食是影响菌群最直接的杠杆，尤其是多样化纤维。
2. 益生菌效果具有**菌株特异性**，不同菌株不能互相替代。
3. 健康人长期补充益生菌的益处证据不足。
4. 菌群检测目前临床指导价值有限，不建议据此盲目购买产品。

## 菌群的基本功能

- 发酵未消化的碳水，产生短链脂肪酸（乙酸、丙酸、丁酸）
- 合成部分维生素（如维生素 K、部分 B 族）
- 参与胆酸和药物代谢
- 训练免疫系统，维持肠道屏障
- 与肠脑轴互动，影响情绪和食欲（机制仍在研究）

## 影响菌群的因素

| 因素 | 影响 |
|---|---|
| 饮食 | 纤维、发酵食品、超加工食品 |
| 抗生素 | 短期显著改变组成，部分可恢复 |
| 出生方式与喂养 | 剖宫产、母乳/配方影响早期定植 |
| 地理与文化 | 长期饮食模式差异 |
| 睡眠与压力 | 通过肠脑轴影响 |
| 药物 | 抑酸药、二甲双胍等 |
| 运动 | 适度运动与多样性相关 |

## 怎么吃对菌群

1. 每天 25~30 克膳食纤维，来自全谷物、豆类、蔬果、坚果。
2. 增加纤维**多样性**，不同纤维喂养不同菌群。
3. 适量发酵食品：无糖酸奶、纳豆、豆豉、泡菜（注意盐）。
4. 减少超加工食品和高糖饮食。
5. 不需要每天服用益生菌来“维护菌群”。

“每周 30 种植物性食物”来自 American Gut Project 的观察性研究，与菌群多样性相关，可以作为多样化目标，但不是硬性医学标准。

## 益生菌、益生元、后生元

| 概念 | 定义 | 例子 |
|---|---|---|
| 益生菌 | 足量摄入对健康有益的活微生物 | 特定乳酸菌、双歧杆菌菌株 |
| 益生元 | 被有益菌选择性利用的底物 | 菊粉、低聚果糖、低聚半乳糖 |
| 合生元 | 益生菌 + 益生元 | 复合制剂 |
| 后生元 | 微生物代谢产物或灭活菌体 | 短链脂肪酸、部分细胞壁成分 |

## 益生菌的证据

| 场景 | 证据 |
|---|---|
| 抗生素相关腹泻 | 中等，部分菌株有效 |
| 肠易激综合征 | 中等，效果因菌株和个体而异 |
| 炎症性肠病 | 有限，特定情况如 pouchitis |
| 健康人日常保健 | 不足 |
| 儿童过敏预防 | 证据不一致，不建议常规 |

使用注意：

- 免疫抑制、危重患者、中心静脉导管者使用前需医生评估。
- 益生菌不是药物，不能替代治疗。
- 看菌株、剂量和活菌数，不只看“益生菌”三个字。

## 菌群检测

- 菌群组成受采样、饮食、时间影响，波动大。
- 多数商业检测不能给出可靠的个体化饮食建议。
- 检测结果不能诊断疾病，也不能替代医生评估。
- 有胃肠症状，优先做正规检查，而不是买菌群检测。

## 常见误区

1. **“益生菌人人需要”**：健康人长期补充证据不足。
2. **“菌群检测能指导一切”**：目前临床价值有限。
3. **“发酵食品越酸越好”**：酸度不等于活菌数量。
4. **“排毒能改善菌群”**：没有证据，可能破坏肠道环境。
5. **“益生菌能减肥”**：证据弱，不能替代饮食和运动。

## 实操建议

1. 先增加纤维多样性，再考虑补剂。
2. 每周安排豆类、全谷物、蔬果、坚果。
3. 适量无糖酸奶或发酵食品。
4. 使用抗生素后如有腹泻，咨询医生是否适合益生菌。
5. 免疫抑制或重症患者，不自行使用益生菌。
