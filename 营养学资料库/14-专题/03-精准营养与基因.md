# 精准营养与基因

## 核心结论

精准营养的目标是根据个体特征给出更合适的饮食建议，但目前：

1. **生物标志物**（血脂、血糖、维生素 D、铁蛋白）最可操作。
2. **基因检测**对多数人的饮食指导作用有限，效应量小。
3. **微生物组检测**的临床指导价值仍在研究中。
4. 饮食行为、环境、经济和文化因素，往往比基因更重要。
5. 不要用“基因决定”作为放弃健康饮食的理由。

## 精准营养的层次

| 层次 | 内容 | 当前应用 |
|---|---|---|
| 基因 | 单基因变异、多基因风险评分 | 少数明确场景 |
| 表观遗传 | 基因表达受环境调节 | 研究阶段 |
| 微生物组 | 肠道菌群组成与功能 | 研究阶段，检测有限 |
| 生物标志物 | 血脂、血糖、维生素、铁 | 临床应用成熟 |
| 行为与环境 | 饮食记录、睡眠、压力、食物环境 | 最可干预 |

## 几个常见基因例子

| 基因/特征 | 影响 | 现实意义 |
|---|---|---|
| 乳糖酶持续表达 | 成年后能否消化乳糖 | 乳糖不耐受者可选择无乳糖奶或酸奶 |
| CYP1A2 | 咖啡因代谢速度 | 慢代谢者可能对咖啡因更敏感，但证据不一致 |
| FTO | 肥胖风险 | 效应小，运动和饮食仍占主导 |
| MTHFR | 叶酸代谢 | 多数变异不改变常规叶酸建议 |
| HLA-DQ2/DQ8 | 乳糜泻风险 | 用于诊断支持，不能自行据此判断 |
| 盐敏感性 | 血压对钠的反应 | 高盐人群限盐获益更大，但难以简单检测 |

## 基因检测的局限

- 多数饮食相关基因的效应量很小，不能准确预测个体反应。
- 多基因风险评分的预测能力有限，且研究人群以欧洲裔为主。
- 直接面向消费者的检测可能存在隐私和误导风险。
- 检测结果可能带来焦虑，却不能给出明确行动。
- 基因不是命运，环境和行为的影响很大。

## 微生物组检测

- 菌群组成受采样、饮食、时间和方法影响，波动大。
- 多数商业检测无法给出可靠的个体化饮食处方。
- 检测结果不能诊断疾病。
- 有胃肠症状，应做正规检查，而不是买菌群检测。

## 真正可操作的“精准”

| 指标 | 能指导什么 |
|---|---|
| 血脂谱 | 脂肪质量、是否需要药物 |
| 空腹血糖/HbA1c | 碳水质量和血糖管理 |
| 铁蛋白/血常规 | 是否需要补铁 |
| 25(OH)D | 是否需要补维生素 D |
| 血压 | 钠钾平衡、体重管理 |
| 尿酸 | 嘌呤、果糖、酒精 |
| 食物过敏/不耐受检测 | 仅在明确适应证下，由医生判断 |
| 饮食记录 | 找出个体化缺口和触发场景 |

## 常见误区

1. **“基因检测能告诉我该吃什么”**：多数情况下不能，效应太小。
2. **“我有肥胖基因，减不下来”**：基因影响风险，不决定结果。
3. **“菌群检测能定制饮食”**：目前证据不足。
4. **“精准营养就是买检测”**：更重要的是评估、行为和随访。
5. **“别人有效的方案对我一定有效”**：个体差异真实存在，需要试错和调整。

## 实操建议

1. 先做基础体检和饮食评估，再考虑基因或菌群检测。
2. 用可改变的因素制定方案：饮食结构、份量、运动、睡眠。
3. 有明确家族史或遗传病风险，找遗传咨询。
4. 不根据商业检测报告自行大改饮食或停药。
5. 每 3~6 个月复盘指标和行为，动态调整。
