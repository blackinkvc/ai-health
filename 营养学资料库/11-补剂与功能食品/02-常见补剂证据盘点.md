# 常见补剂证据盘点

## 核心结论

补剂不是“有或没有”的二选一，而是**分人群、分剂量、分证据强度**：

| 证据等级 | 含义 | 例子 |
|---|---|---|
| A 强 | 多项高质量研究一致 | 叶酸预防神经管缺陷、B12 治疗缺乏、肌酸增肌 |
| B 中等 | 有一定证据，但有限制 | 益生菌预防抗生素相关腹泻、维生素 D 纠正缺乏 |
| C 弱 | 小样本、短期或结果不一致 | 胶原蛋白改善皮肤、益生菌改善 IBS |
| D 无/有害 | 证据不足或风险大于收益 | 燃脂丸、睾酮促进剂、吸烟者补 β-胡萝卜素 |

## 常见补剂一览

| 补剂 | 证据 | 适用人群 | 备注 |
|---|---|---|---|
| 复合维生素 | 弱 | 饮食严重不均衡、吸收不良者 | 健康人预防慢病证据不足 |
| 维生素 D | 中~强（缺乏者） | 日晒不足、老年人、缺乏者 | 按血 25(OH)D 和 UL 补充 |
| 钙 | 中 | 饮食不足者 | 食物优先，单次 ≤500 毫克 |
| 鱼油/omega-3 | 中（高甘油三酯） | 甘油三酯高、吃鱼少者 | 低剂量对心血管事件证据有限 |
| 蛋白粉 | 强（补充蛋白） | 蛋白需求高、饮食不便者 | 不是“增肌神药” |
| 益生菌 | 中（特定菌株） | 抗生素相关腹泻、部分 IBS | 菌株和剂量决定效果 |
| 胶原蛋白 | 弱~中 | 皮肤、关节诉求者 | 不如完整蛋白，效果有限 |
| 氨基葡萄糖/软骨素 | 弱 | 骨关节炎 | 多项研究显示获益很小 |
| 肌酸 | 强 | 力量、爆发力训练者 | 3~5 克/天，安全 |
| 咖啡因 | 强 | 耐力、警觉性 | 注意睡眠和心悸 |
| β-丙氨酸 | 中 | 1~4 分钟高强度项目 | 可能刺痛感 |
| BCAA | 弱 | 蛋白质摄入不足者 | 完整蛋白更好 |
| 燃脂丸 | 无 | 不推荐 | 心悸、血压、违禁成分风险 |

## 重点说明

### 复合维生素

- 对营养充足的健康人，预防心血管疾病和癌症的证据不足。
- 不能替代蔬菜水果和全谷物。
- 饮食严重受限、吸收不良、减重手术后可能需要。
- 选择剂量接近 RNI 的产品，避免超高剂量。

### 维生素 D

- 缺乏者补充有明确获益。
- 对普通人群预防骨折、跌倒的证据不一致，高剂量可能增加跌倒风险。
- 建议检测 25(OH)D 后个体化补充，不要盲目长期大剂量。
- 与钙一起补充时，注意总剂量和 UL。

### 钙

- 饮食不足者可补充，单次不超过 500 毫克，分次吸收更好。
- 食物来源优先：奶、豆腐、绿叶菜、小鱼。
- 过量增加便秘、肾结石和心血管风险争议。
- 与维生素 D 同补，但不要超 UL。

### 鱼油与 omega-3

- 高剂量处方级 omega-3 可用于高甘油三酯，需医生评估。
- 普通低剂量鱼油对心血管事件的预防证据有限。
- 吃鱼 2 次/周是更推荐的来源。
- 高剂量可能增加出血风险，与抗凝药同服需谨慎。

### 蛋白粉

- 本质是方便的蛋白质来源，不是“增肌药”。
- 乳清蛋白吸收快，酪蛋白慢，大豆蛋白适合素食者。
- 饮食蛋白足够时，额外蛋白粉没有额外增肌效果。
- 选择配料简单、蛋白质含量高、添加糖少的产品。

### 益生菌

- 效果具有**菌株特异性**，不同菌株不能互相替代。
- 抗生素相关腹泻、部分 IBS 有中等证据。
- 健康人日常补充的长期益处证据不足。
- 免疫抑制、危重患者使用前需医生评估。

### 胶原蛋白

- 部分研究显示对皮肤水分、弹性和关节疼痛有轻微改善。
- 证据质量不高，效果有限。
- 胶原蛋白缺乏色氨酸，不是优质蛋白，不能替代蛋奶鱼肉。
- 想补蛋白，完整蛋白更划算。

### 肌酸

- 提高力量、爆发力和瘦体重，证据强。
- 3~5 克/天，无需冲击期。
- 可能导致体重增加（水分），肾功能正常者安全。
- 肾病患者使用前咨询医生。

## 常见误区

1. **“复合维生素能预防癌症”**：证据不足，吸烟者补 β-胡萝卜素反而有害。
2. **“鱼油能替代他汀”**：不能，鱼油主要降甘油三酯。
3. **“胶原蛋白能补到脸上”**：吃进去会被分解成氨基酸，效果有限。
4. **“益生菌人人有益”**：菌株特异性强，健康人长期益处证据不足。
5. **“天然燃脂丸安全”**：可能含违禁成分，风险高。

## 实操建议

1. 先确定目标：纠正缺乏、补充蛋白、改善表现，还是跟风？
2. 有缺乏风险先检测，不凭感觉补。
3. 一次只加一种，记录效果和不良反应。
4. 对照 UL，避免多种产品叠加。
5. 选择有第三方检测的产品，告诉医生你在吃什么。
