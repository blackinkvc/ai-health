# 补剂选购与风险

## 核心结论

补剂的风险主要来自四件事：

1. **不需要却长期吃**：浪费钱，增加过量风险。
2. **剂量超标**：多种产品叠加，超过 UL。
3. **药物相互作用**：影响药效或增加出血、毒性。
4. **产品污染**：重金属、违禁药物、虚假标注。

选购的核心不是“买最贵的”，而是**买对、买够、买干净**。

## 选购前先问五个问题

1. 我是否有明确的缺乏风险或检测证据？
2. 食物能不能解决？
3. 需要多大剂量？是否接近 UL？
4. 我正在吃什么药？有没有相互作用？
5. 产品是否有第三方检测和透明标签？

## 看标签

| 项目 | 要看什么 |
|---|---|
| 成分 | 每种成分的具体名称和剂量 |
| 剂量 | 每份含量 vs 每日份数 |
| 形式 | 例如维生素 D3、柠檬酸钙、甲基叶酸 |
| 辅料 | 是否含常见过敏原 |
| 认证 | NSF、USP、Informed Sport 等 |
| 警示 | 适宜人群、禁忌、药物相互作用 |
| 生产信息 | 批号、保质期、厂家 |

避免：

- “专利混合物”（proprietary blend）不标具体剂量。
- 宣称“一瓶解决多种问题”。
- 没有中文标签的跨境产品。
- 夸大“临床验证”“专家推荐”但无出处。

## 剂量与 UL

- 对照《中国居民膳食营养素参考摄入量》的 RNI 和 UL。
- 多种产品叠加时，把同一种营养素的总量加起来。
- 脂溶性维生素 A、D、E、K 和铁、硒、锌更要注意蓄积和过量。
- 水溶性维生素也不是无限安全，B6、烟酸、维生素 C 过量有风险。

## 第三方检测

| 认证 | 说明 |
|---|---|
| NSF Certified for Sport | 针对运动补剂，检测违禁物质 |
| USP Verified | 成分、纯度、溶出度 |
| Informed Sport | 批次检测违禁物质 |
| 蓝帽子 | 中国保健食品注册/备案，不等于第三方质量认证 |

第三方检测不能保证“有效”，但能降低污染和标注不符的风险。

## 药物相互作用

| 补剂 | 可能相互作用的药物 | 风险 |
|---|---|---|
| 维生素 K | 华法林 | 降低抗凝效果 |
| 鱼油高剂量 | 抗凝/抗血小板药 | 出血风险 |
| 钙、铁、镁 | 左甲状腺素、部分抗生素 | 影响吸收，需错开 |
| 圣约翰草 | 抗抑郁药、免疫抑制剂、口服避孕药 | 诱导肝酶，降低药效 |
| 银杏 | 抗凝药 | 出血风险 |
| 高剂量维生素 E | 抗凝药 | 出血风险 |
| 钾补充剂 | ACEI/ARB、保钾利尿剂 | 高钾血症 |

服用处方药者，添加任何补剂前先问医生或药师。

## 特殊人群

| 人群 | 注意 |
|---|---|
| 孕期/哺乳期 | 只补医生建议的叶酸、铁、钙、DHA、维生素 D |
| 儿童 | 不自行使用成人补剂，按儿科建议 |
| 老年人 | 注意多重用药和相互作用 |
| 肝肾疾病 | 蛋白粉、钾、镁、维生素 A 等需个体化 |
| 术前 | 部分补剂需提前停用，告知医生 |
| 运动员 | 注意违禁成分，选择第三方检测产品 |

## 常见风险信号

1. 宣称“根治”“替代药物”“无副作用”。
2. 承诺“快速见效”“一个月瘦 20 斤”。
3. 没有具体成分和剂量。
4. 价格异常高，靠会销或熟人推销。
5. 要求停用处方药。
6. 无生产厂家、无批号、无中文标签。

## 常见误区

1. **“剂量越高效果越好”**：超过 UL 可能有害。
2. **“天然提取物没有副作用”**：可能伤肝、干扰药物。
3. **“进口补剂更安全”**：监管和标签质量参差。
4. **“复合配方更方便”**：成分重叠，容易超量。
5. **“吃了没感觉就是没用”**：多数补剂本来就没有“感觉”，要看指标和目标。

## 实操建议

1. 列出正在服用的所有补剂和药物，交给医生或药师核对。
2. 一次只加一种，观察 2~4 周。
3. 优先选择成分单一、剂量透明、有第三方检测的产品。
4. 术前、孕期、哺乳期、儿童使用前咨询专业人士。
5. 出现皮疹、腹泻、心悸、出血等，立即停用并就医。
