# 膳食补充剂总论

## 核心结论

补剂市场巨大，但真正需要补的人没有想象中多：

1. 优先从多样化膳食获取营养。
2. 有明确缺乏风险或检测证据时才补。
3. 补剂不能替代药物，也不能替代食物。
4. “天然”“进口”“高端”不等于安全有效。

## 什么是膳食补充剂

常见类别：

| 类别 | 例子 |
|---|---|
| 维生素 | 维生素 D、B 族、维生素 C |
| 矿物质 | 钙、铁、锌、硒、镁 |
| 蛋白质与氨基酸 | 乳清蛋白、大豆蛋白、BCAA |
| 脂肪酸 | 鱼油、藻油 DHA、亚麻籽油 |
| 益生菌 | 乳酸菌、双歧杆菌制剂 |
| 植物提取物 | 人参、银杏、姜黄、绿茶提取物 |
| 运动补剂 | 肌酸、咖啡因、β-丙氨酸 |
| 代餐与营养粉 | 代餐奶昔、全营养配方粉 |

## 谁可能真正需要

| 人群 | 可能需要的补充 |
|---|---|
| 备孕及孕早期 | 叶酸 |
| 孕期/哺乳期 | 铁、钙、DHA、维生素 D（按医嘱） |
| 严格素食者 | 维生素 B12、铁、锌、DHA |
| 老年人 | 维生素 D、B12、蛋白质（按需） |
| 日晒不足者 | 维生素 D |
| 确诊缺铁性贫血 | 铁剂（医生指导） |
| 吸收不良、减重手术后 | 多种维生素和矿物质 |
| 特殊疾病 | 按临床需要，如肾病、肝病、肿瘤 |

没有上述情况、饮食均衡的健康人，通常不需要复合维生素。

## 补剂的风险

| 风险 | 说明 |
|---|---|
| 过量中毒 | 维生素 A、D、铁、硒等有明确 UL |
| 药物相互作用 | 维生素 K 与华法林、钙铁与甲状腺素、圣约翰草与多种药物 |
| 掩盖疾病 | 贫血、甲状腺问题被补剂掩盖，延误诊断 |
| 污染 | 重金属、违禁药物、微生物 |
| 虚假宣传 | 夸大功效、冒充药物、无效退款骗局 |
| 经济负担 | 长期购买高价低效产品 |

## 证据怎么看

- 缺乏人群补充有明确获益（如叶酸预防神经管缺陷、B12 治疗缺乏）。
- 营养充足人群额外补充，多数没有额外健康收益。
- 单一研究、动物实验、体外实验不能直接证明人体有效。
- 大剂量抗氧化剂可能有害（如吸烟者补 β-胡萝卜素）。
- 选择有第三方检测、成分透明的产品。

## 选购原则

1. **先评估**：饮食、症状、化验，确有必要再补。
2. **单一成分优先**：避免“一瓶包治百病”的复合配方。
3. **看剂量**：对照 RNI 和 UL，避免多种产品叠加超量。
4. **看形式**：不同形式吸收率不同，但不必迷信“高级形式”。
5. **看第三方检测**：NSF、USP、Informed Sport 等。
6. **看标签**：避免“专利混合物”隐藏剂量。

## 常见误区

1. **“补剂能弥补糟糕饮食”**：补剂缺少纤维、蛋白质和植物化学物。
2. **“天然一定安全”**：植物提取物也可能伤肝、干扰药物。
3. **“多吃几种更全面”**：成分重叠容易超量。
4. **“进口的更可靠”**：监管和标签质量参差，关键看证据和检测。
5. **“人人都该吃复合维生素”**：饮食均衡者通常不需要。

## 实操建议

1. 先记录一周饮食，看是否真的存在缺口。
2. 有症状或高风险，先做相关检查。
3. 需要补时，一次只加一种，观察反应。
4. 把正在吃的补剂告诉医生，避免相互作用。
5. 不用于替代药物或正规治疗。
