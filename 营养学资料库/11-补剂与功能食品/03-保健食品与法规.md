# 保健食品与法规

## 核心结论

保健食品在中国属于特殊食品，监管比普通食品严，但仍**不是药品**：

1. 允许声称特定保健功能，不允许声称疾病预防或治疗。
2. 必须标注“本品不能代替药物”。
3. 正规产品有“蓝帽子”标志和批准/备案文号。
4. 广告不得使用医疗术语、不得夸大功效。
5. 会销、免费体检、专家义诊是虚假宣传高发场景。

## 什么是保健食品

保健食品指声称具有特定保健功能，或以补充维生素、矿物质为目的的食品。

特点：

- 适用于特定人群
- 调节机体功能，不以治疗疾病为目的
- 对人体不产生急性、亚急性或慢性危害
- 形式可以是片剂、胶囊、粉剂、口服液等

## 蓝帽子与批准文号

| 类型 | 标识 | 说明 |
|---|---|---|
| 注册制 | 国食健注 G/J | G 为国产，J 为进口；需提交功能和安全证据 |
| 备案制 | 食健备 G/J | 主要用于营养素补充剂等风险较低产品 |
| 普通食品 | 无蓝帽子 | 不能声称保健功能 |

验证方法：

1. 看包装是否有蓝帽子标志。
2. 看批准文号或备案号。
3. 到国家市场监督管理总局特殊食品信息查询平台核对。
4. 核对产品名称、企业、功能声称是否一致。

查不到、信息不符，基本可以判定有问题。

## 功能声称的边界

- 保健功能实行目录管理，只能声称目录内的功能。
- 不能声称“治疗”“治愈”“根治”“预防某种疾病”。
- 不能替代药物治疗。
- 不能利用“专家”“患者案例”“有效率”等作证明。
- 不能与药品比较疗效。

常见违规话术：

- “降血糖、降血压、降血脂，不用吃药”
- “疗程服用，根治某某病”
- “最新诺贝尔奖技术”
- “无效退款，全国包邮”
- “医院不让卖，我们这里有”

## 标签要看什么

| 项目 | 内容 |
|---|---|
| 蓝帽子 | 保健食品标志 |
| 批准文号 | 国食健注/食健备 |
| 保健功能 | 目录内的功能声称 |
| 适宜人群 | 谁能吃 |
| 不适宜人群 | 谁不能吃 |
| 食用方法 | 剂量和频次 |
| 注意事项 | “本品不能代替药物” |
| 生产日期/保质期 | 是否过期 |
| 生产企业 | 名称和地址 |

## 广告与宣传

- 不得涉及疾病预防、治疗功能。
- 不得使用医疗用语或易与药品混淆的用语。
- 不得夸大保健功能。
- 不得利用广告代言人作推荐、证明（保健食品广告有严格限制）。
- 不得声称“安全无副作用”“纯天然无依赖”。

## 常见骗局

1. **免费体检、免费旅游**：先用“检测”制造焦虑，再推销高价产品。
2. **专家义诊、健康讲座**：假专家、假案例。
3. **会销**：封闭环境、限时优惠、情感攻势。
4. **冒充药品**：把保健食品说成“特效药”。
5. **伪造批准文号**：包装看起来正规，官网查不到。
6. **海外代购**：无中文标签，无法核对国内监管信息。

## 常见误区

1. **“蓝帽子就是药品”**：保健食品不是药，不能治病。
2. **“有批准文号就一定有效”**：只代表合法合规，不代表对每个人都有效。
3. **“进口的监管更严”**：不同国家法规不同，代购产品未必符合国内标准。
4. **“纯天然没有副作用”**：植物成分也可能伤肝、干扰药物。
5. **“吃了没效果是吃的时间不够”**：可能是产品本身没有证据。

## 实操建议

1. 先问自己：我是缺营养，还是有疾病？疾病找医生。
2. 买前查蓝帽子和批准文号。
3. 看适宜/不适宜人群和剂量，不超量。
4. 不相信“根治”“替代药物”的宣传。
5. 保留发票和包装，出现不适及时停用并就医。
6. 把正在服用的保健食品告诉医生。
