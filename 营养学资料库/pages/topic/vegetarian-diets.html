素食与弹性素食

计划良好的素食可以很健康，但纯素必须主动补 B12；弹性素食是更容易长期坚持的折中方案。

doc

核心结论

素食的健康效应取决于怎么吃，而不是“是否吃肉”：

  1. 以蔬菜、水果、全谷物、豆类、坚果为主的素食，与较低 BMI、较低 LDL-C 和较低缺血性心脏病风险相关。
  2. 纯素饮食最容易缺 B12，必须通过强化食品或补充剂获得。
  3. 铁、锌、钙、omega-3、维生素 D 也需要主动规划。
  4. 弹性素食（少量吃肉、以植物为主）通常更容易长期坚持。

素食的类型

类型 吃什么 不吃什么
弹性素食 以植物为主，偶尔吃少量肉 不严格排除
鱼素 植物 + 鱼虾 禽畜肉
蛋奶素 植物 + 蛋 + 奶 禽畜肉、鱼虾
奶素 植物 + 奶 蛋、肉、鱼
蛋素 植物 + 蛋 奶、肉、鱼
纯素 只吃植物性食物 所有动物性食物

关键营养素

营养素 风险 解决方案
维生素 B12 纯素者几乎必然缺乏，可致贫血和神经损伤 强化食品（强化植物奶、营养酵母）或 B12 补充剂
蛋白质 植物蛋白消化率略低，赖氨酸可能不足 豆类 + 谷物搭配，每餐安排豆制品
铁 非血红素铁吸收率低 搭配维生素 C，避免浓茶咖啡，必要时补铁
锌 植酸抑制吸收 浸泡、发芽、发酵，增加坚果和种子
钙 不喝奶时容易不足 强化植物奶、北豆腐、绿叶菜、芝麻酱
Omega-3 ALA 转化 EPA/DHA 效率低 亚麻籽、奇亚籽、核桃；考虑藻油 DHA
维生素 D 日晒不足时普遍不足 日晒、强化食品、补充剂
碘 纯素者可能不足 碘盐、海藻（注意碘过量）

蛋白质搭配

植物蛋白的“短板”可以用搭配弥补：

  • 谷物缺赖氨酸 → 搭配豆类（米饭 + 豆腐、面包 + 鹰嘴豆泥）
  • 豆类缺蛋氨酸 → 搭配谷物或坚果
  • 大豆蛋白质量较高，是素食者的核心蛋白来源
  • 每餐安排一个蛋白质来源：豆腐、豆浆、豆干、鹰嘴豆、扁豆、藜麦

证据与边界

  • 观察性研究显示，素食者 BMI 较低，缺血性心脏病风险较低。
  • EPIC-Oxford 研究发现，素食者缺血性心脏病风险较低，但出血性卒中风险略高，机制可能与低胆固醇、低 B12 或低 omega-3 有关。
  • 素食与 2 型糖尿病、部分癌症风险降低相关，但混杂因素较多。
  • 骨密度：纯素者骨折风险可能略高，需保证钙、维生素 D 和蛋白质。
  • 心理健康：证据不一致，不能简单说“素食改善情绪”。

结论：素食可以健康，但不是自动健康，需要计划。

特殊人群

人群 注意点
孕期/哺乳期 必须保证 B12、铁、DHA、碘、维生素 D，建议营养师随访
婴幼儿 纯素喂养风险较高，需专业指导，保证能量和蛋白质
儿童青少年 关注生长曲线、铁、锌、钙、B12
老年人 蛋白质需求高，注意肌肉流失和 B12 吸收
运动员 蛋白质和总热量需求高，注意铁和肌酸

一日纯素示例

餐次 内容
早餐 强化豆奶 + 燕麦 + 蓝莓 + 亚麻籽
午餐 糙米饭 + 麻婆豆腐（少油）+ 炒西兰花
加餐 鹰嘴豆泥 + 胡萝卜条 + 一小把核桃
晚餐 藜麦 + 扁豆炖菜 + 菠菜
补充 B12 补充剂，必要时藻油 DHA、维生素 D

常见误区

  1. “素食一定健康”：薯条、甜饮料、精制糕点也可以是纯素。
  2. “植物里含有 B12”：植物性食物基本不含有效 B12，紫菜中的类似物不能替代。
  3. “大豆会让男性雌化”：正常摄入量的大豆异黄酮没有证据支持这一说法。
  4. “纯素孩子自然更健康”：需要严格规划，否则生长和神经发育风险高。
  5. “弹性素食就是偶尔吃素”：核心是整体以植物为主，减少红肉和加工肉。

实操建议

  1. 先从每周 2 天无肉日开始，再逐步增加植物性比例。
  2. 每餐按“豆类 + 全谷物 + 蔬菜 + 坚果/种子”组合。
  3. 纯素者把 B12 当作必需补充，不要靠“感觉”判断。
  4. 补铁餐搭配维生素 C，避免同时喝茶和咖啡。
  5. 孕期、哺乳期、儿童和老年人采用素食前，先咨询注册营养师。
