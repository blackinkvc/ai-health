时间营养学

进食时间会影响血糖和代谢，但总热量仍是基础；规律作息、把主要热量放在白天，比追求某个“神奇时段”更实际。

doc

核心结论

时间营养学研究进食时间与生物钟、代谢的相互作用：

  1. 人体胰岛素敏感性在白天较高，夜间较低。
  2. 深夜进食与体重增加、血糖控制变差相关。
  3. 限时进食（TRE）有助于部分人控制热量，但不比同等热量的常规饮食更神奇。
  4. 规律作息和稳定的进食节奏，比追求“最佳时间点”更重要。

生物钟与代谢

  • 下丘脑视交叉上核是主时钟，肝脏、肌肉、脂肪组织也有外周时钟。
  • 生物钟调节胰岛素分泌、糖异生、脂肪合成和体温。
  • 睡眠不足、轮班工作会打乱节律，增加肥胖和 2 型糖尿病风险。
  • 进食时间本身就是给外周时钟的信号。

进食时间的影响

时间 代谢特点 建议
早晨 胰岛素敏感性较高 适合安排主食和蛋白质
中午 代谢活跃 可以是全天最大的一餐
傍晚 逐渐下降 晚餐适量，避免过晚
深夜 胰岛素敏感性低 尽量避免高糖高脂夜宵

限时进食（TRE）

  • 常见形式：每天 8~10 小时进食窗口，其余时间禁食。
  • 研究显示，TRE 的减重效果与同等热量的常规饮食相近。
  • 部分人更容易控制总热量，因为它减少了夜宵和零食机会。
  • 风险：饥饿、头晕、社交不便、肌肉流失（蛋白质不足时）。
  • 不适合：孕期哺乳期、青少年、进食障碍史、糖尿病患者（尤其使用胰岛素或磺脲类）、体重过低者。

早餐

  • 观察性研究显示吃早餐与较低肥胖风险相关，但因果证据不足。
  • 早餐对部分人有助于稳定食欲和血糖，对另一些人并非必需。
  • 关键是全天总摄入和饮食质量。
  • 如果吃早餐，选择蛋白质 + 全谷物 + 蔬果，而不是高糖糕点。

夜宵

  • 夜间进食与体重增加、胃食管反流和睡眠质量下降相关。
  • 如果确实饿，选择少量蛋白质或蔬菜，如无糖酸奶、鸡蛋、牛奶。
  • 避免高糖高脂零食和酒精。
  • 晚餐与睡眠间隔 2~3 小时。

轮班与倒时差

  • 轮班工作者代谢风险更高，尽量固定进食时间。
  • 夜班时选择清淡、高蛋白、低糖食物，避免大量咖啡因。
  • 下班后保证睡眠，避免用高热量食物“提神”。
  • 倒时差时，按目的地时间安排光照和进食。

运动时间

  • 运动表现通常在下午至傍晚较好，但个体差异大。
  • 训练时间应与进食、睡眠和工作安排协调。
  • 训练前 1~3 小时吃碳水 + 少量蛋白质。
  • 不必为了“最佳时间”打乱可执行的计划。

常见误区

  1. “晚上吃碳水一定胖”：总热量比时间更重要，但深夜高热量进食确实容易过量。
  2. “早餐是所有人最重要的一餐”：对部分人有益，但不是绝对必需。
  3. “8 点后不能吃东西”：关键是晚餐时间和总摄入，不是某个固定钟点。
  4. “限时进食能自动减脂”：它主要通过减少总摄入起作用。
  5. “错过窗口就白练了”：全天蛋白质和总热量更重要。

实操建议

  1. 固定三餐时间，周末不要相差太大。
  2. 把主要热量放在白天，晚餐适量。
  3. 睡前 2~3 小时不进食。
  4. 如果尝试 TRE，从 12 小时窗口开始，逐步缩短。
  5. 轮班或糖尿病用药者，调整进食时间前咨询医生。
