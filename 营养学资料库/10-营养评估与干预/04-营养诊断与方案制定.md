# 营养诊断与方案制定

## 核心结论

营养干预不是“看到异常就补”，而是按标准流程：

**评估 → 诊断 → 干预 → 监测与评价**

其中营养诊断是把评估结果转成可处理问题的关键一步。一个好的诊断要回答：

1. 问题是什么？
2. 由什么原因导致？
3. 有哪些证据？

## 营养护理流程（NCP）

| 步骤 | 内容 | 产出 |
|---|---|---|
| 评估 | 膳食、体格、生化、临床、病史 | 数据和问题清单 |
| 诊断 | 用标准术语描述营养问题 | PES 陈述 |
| 干预 | 饮食、教育、咨询、营养支持 | 具体方案 |
| 监测与评价 | 跟踪指标、调整方案 | 效果判断 |

## PES 陈述

**P（Problem）问题 + E（Etiology）原因 + S（Signs/Symptoms）表现**

示例：

> 蛋白质摄入不足（P），与食欲下降、咀嚼困难和独居有关（E），表现为每日蛋白质摄入约 35 克、1 个月体重下降 5%、白蛋白偏低（S）。

好的 PES 特点：

- 问题具体，不用“营养不良”一笔带过。
- 原因指向可干预的因素。
- 表现有数据或体征支持。
- 不把疾病诊断写成营养诊断。

## 营养诊断的类别

| 类别 | 例子 |
|---|---|
| 摄入问题 | 能量摄入不足、蛋白质摄入不足、铁摄入不足 |
| 临床问题 | 体重下降、营养不良、吞咽困难、食物过敏 |
| 行为与环境 | 进食行为异常、食物获取困难、营养知识不足 |

## 制定目标

目标要 SMART：

| 要素 | 说明 | 示例 |
|---|---|---|
| Specific 具体 | 明确要改变什么 | 每天增加 20 克蛋白质 |
| Measurable 可测 | 有数字或标准 | 从 35 克增加到 55 克 |
| Achievable 可实现 | 符合能力和资源 | 通过早餐加蛋和奶实现 |
| Relevant 相关 | 与诊断直接相关 | 改善体重下降和肌肉流失 |
| Time-bound 有时限 | 设定复查时间 | 4 周后复查体重和白蛋白 |

## 干预措施

| 类型 | 内容 |
|---|---|
| 饮食调整 | 改变食物种类、份量、餐次、质地 |
| 营养教育 | 教看标签、搭配、烹饪 |
| 营养咨询 | 行为改变、动机访谈、解决问题 |
| 口服营养补充 | 高能量高蛋白饮品，作为补充而非替代 |
| 肠内营养 | 管饲，优先于肠外 |
| 肠外营养 | 静脉营养，肠道无法使用时 |
| 协调转诊 | 医生、护士、康复、心理、社工 |

## 监测与评价

| 指标 | 频率 |
|---|---|
| 体重 | 每周 1~2 次 |
| 饮食记录 | 每周 3 天 |
| 腰围/体成分 | 每月 |
| 白蛋白、血红蛋白、电解质 | 按病情 |
| 症状（食欲、吞咽、腹泻） | 每次随访 |
| 依从性 | 每次随访 |

评价时要问：目标达成了吗？没达成的原因是什么？方案需要调整吗？

## 记录格式（ADIME）

- **A**ssessment：评估数据
- **D**iagnosis：PES 诊断
- **I**ntervention：干预措施
- **M**onitoring/Evaluation：监测计划和结果
- **E**valuation：效果评价

## 常见误区

1. **“诊断就是贴标签”**：诊断要指向可干预的原因。
2. **“目标越大越好”**：不切实际的目标降低依从性。
3. **“只开食谱，不教方法”**：没有行为改变，方案难以持续。
4. **“只补营养，不管病因”**：吞咽、贫困、抑郁、药物等都可能导致营养不良。
5. **“一次方案管到底”**：需要随访和动态调整。

## 实操建议

1. 先用 ABCD 收集数据，再写 PES。
2. 一次只解决 1~2 个最重要的问题。
3. 目标写成可量化的数字和时间。
4. 方案要包含“吃什么、怎么吃、谁来支持、何时复查”。
5. 用 ADIME 记录，方便团队协作和追踪。
