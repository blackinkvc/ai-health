# 生化与临床评估

## 核心结论

生化指标是营养评估的一部分，不是全部：

1. 单项异常不能诊断营养不良，必须结合饮食、体格、症状和病史。
2. 炎症、脱水、肝肾功能和药物都会影响指标。
3. 白蛋白和前白蛋白不是短期营养状况的可靠指标。
4. 临床体征（皮肤、头发、口腔、神经）常被忽视，但很有价值。

## 常用指标

| 指标 | 反映 | 注意 |
|---|---|---|
| 血红蛋白（Hb） | 贫血 | 缺铁、B12/叶酸缺乏、慢性病均可导致 |
| MCV | 红细胞大小 | 小细胞性提示缺铁；大细胞性提示 B12/叶酸缺乏 |
| 铁蛋白 | 铁储备 | 炎症、肝病时升高，可能掩盖缺铁 |
| 转铁蛋白饱和度 | 铁供应 | 受炎症和肝功能影响 |
| 维生素 B12 | B12 状态 | 老年人、素食者、二甲双胍使用者关注 |
| 叶酸 | 叶酸状态 | 孕期、酗酒、吸收不良者关注 |
| 25(OH)D | 维生素 D 储备 | 常用评估指标，不宜盲目追求极高值 |
| 钙、磷、镁 | 电解质和骨代谢 | 受白蛋白、肾功能和激素影响 |
| 白蛋白 | 内脏蛋白、炎症 | 半衰期长，不是短期营养指标 |
| 前白蛋白 | 短期蛋白合成 | 受炎症影响大，不推荐单独用于营养评估 |
| CRP | 炎症 | 升高时铁蛋白、白蛋白解读需谨慎 |
| 血脂谱 | 心血管风险 | 受饮食、体重、遗传和药物影响 |
| 空腹血糖/HbA1c | 糖代谢 | HbA1c 反映近 2~3 个月平均血糖 |
| 肌酐/eGFR | 肾功能 | 决定蛋白质和电解质调整 |
| 肝功能 | 肝损伤、合成能力 | 白蛋白、胆红素、转氨酶 |
| 尿碘 | 碘营养 | 人群监测常用，个体解释有限 |

## 贫血的鉴别

| 类型 | MCV | 常见原因 |
|---|---|---|
| 小细胞性 | 降低 | 缺铁、慢性病、地中海贫血 |
| 正细胞性 | 正常 | 急性失血、慢性病、肾病 |
| 大细胞性 | 升高 | 维生素 B12/叶酸缺乏、酒精、甲状腺功能减退 |

缺铁的诊断通常结合血红蛋白、铁蛋白、转铁蛋白饱和度和临床表现。炎症状态下铁蛋白会升高，需要结合 CRP 解读。

## 白蛋白的误区

- 白蛋白半衰期约 20 天，反映的是较长时间的蛋白状态和炎症水平。
- 手术、感染、创伤时白蛋白下降，不一定是“营养差”。
- 不能仅凭白蛋白决定是否补充蛋白或肠外营养。
- 前白蛋白半衰期短，但同样受炎症影响，不推荐作为单独的营养指标。

## 临床体征

| 部位 | 可能提示 |
|---|---|
| 皮肤 | 干燥、脱屑、瘀斑、伤口愈合差 |
| 头发 | 稀疏、易断、脱发 |
| 眼睛 | 夜盲、干眼、结膜苍白 |
| 口腔 | 口角炎、舌炎、牙龈出血 |
| 指甲 | 匙状甲、脆甲 |
| 神经 | 周围神经病变、认知改变 |
| 肌肉 | 萎缩、无力、水肿 |
| 骨骼 | 畸形、骨痛、骨折风险 |

这些体征不具特异性，需要结合实验室和饮食史。

## 评估模型：ABCD

| 维度 | 内容 |
|---|---|
| A（Anthropometric） | 身高、体重、BMI、腰围、体成分 |
| B（Biochemical） | 血常规、白蛋白、维生素、矿物质、肝肾功能 |
| C（Clinical） | 症状、体征、病史、用药 |
| D（Dietary） | 24 小时回顾、FFQ、记录、食物类别 |

综合四个维度，才能形成合理的营养判断。

## 常见误区

1. **“白蛋白低就是营养不良”**：炎症、肝病、肾病都会导致白蛋白低。
2. **“铁蛋白高就不缺铁”**：炎症时铁蛋白升高，可能掩盖缺铁。
3. **“维生素 D 越高越好”**：超过安全范围没有额外益处，可能有害。
4. **“一次血检正常就代表营养良好”**：指标受多种因素影响，需结合趋势。
5. **“补剂能纠正所有异常”**：先找原因，再谈补充。

## 实操建议

1. 先看血常规、铁蛋白、B12、叶酸、25(OH)D、肝肾功能。
2. 炎症明显时，谨慎解读铁蛋白和白蛋白。
3. 结合饮食史和体重变化，不孤立看单个指标。
4. 异常指标复查确认，必要时转诊。
5. 不自行根据化验单购买补剂。
