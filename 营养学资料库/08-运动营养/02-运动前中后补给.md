# 运动前中后补给

## 核心结论

运动补给的目标是**保证能量、延缓疲劳、促进恢复**，而不是“吃得越多越好”：

1. 练前：1~3 小时吃易消化碳水 + 少量蛋白质。
2. 练中：短时运动喝水即可；超过 60~90 分钟才需要补糖。
3. 练后：蛋白质 0.25~0.3 克/公斤 + 碳水，帮助修复和补充糖原。
4. 补水按体重损失计算，每丢失 1 公斤补 1~1.5 升。

## 运动前

### 时间与内容

| 时间 | 吃什么 |
|---|---|
| 3~4 小时前 | 正餐：主食 + 蛋白质 + 蔬菜，低脂 |
| 1~3 小时前 | 碳水 1~4 克/公斤 + 蛋白质 0.15~0.25 克/公斤 |
| 30~60 分钟前 | 易消化碳水 30~60 克，如香蕉、面包、能量棒 |
| 15 分钟内 | 一般不需要，除非饿了 |

### 原则

- 低脂、低纤维、易消化，避免胃胀。
- 尝试过的食物才在比赛日吃，不要临时换新。
- 容易胃部不适者，把进食时间提前。
- 早晨训练也要吃点碳水，尤其是高强度或长时间训练。

## 运动中

| 运动时长 | 补给 |
|---|---|
| <60 分钟 | 白水即可，通常不需要补糖 |
| 60~90 分钟 | 每小时 30~60 克碳水，可喝水或运动饮料 |
| 90 分钟~2.5 小时 | 每小时 30~60 克碳水，注意电解质 |
| >2.5 小时 | 每小时最高 90 克碳水，使用多种可转运糖（葡萄糖 + 果糖） |

### 补给形式

- 运动饮料：6%~8% 碳水，适合长时间耐力运动。
- 能量胶：方便，需配水，避免高浓度引起胃部不适。
- 香蕉、能量棒、葡萄干：天然食物，适合训练和业余比赛。
- 固体食物在低强度长距离运动中也可使用。

## 运动后

### 蛋白质

- 0.25~0.3 克/公斤体重，约 20~40 克。
- 来源：乳清蛋白、牛奶、鸡蛋、鱼、禽、豆腐。
- 每 3~4 小时再吃一餐含蛋白质的正餐。

### 碳水

- 1~1.2 克/公斤/小时，持续 4~6 小时，补充糖原。
- 高强度或一天两练时更重要。
- 碳水 + 蛋白质组合比只补蛋白更有利于恢复。

### 示例

- 训练后：香蕉 + 牛奶 + 鸡蛋。
- 正餐：米饭 + 鸡胸肉 + 蔬菜。
- 素食：豆浆 + 燕麦 + 豆腐。

## 补水

| 时间 | 建议 |
|---|---|
| 运动前 2~4 小时 | 5~10 毫升/公斤，分次喝 |
| 运动中 | 每 15~20 分钟 150~250 毫升 |
| 运动后 | 每丢失 1 公斤体重补 1~1.5 升 |
| 尿液颜色 | 淡黄色为宜 |

大量出汗时，除水外还需补充钠，可选择含电解质的饮料或少量咸味食物。

## 常见误区

1. **“练后 30 分钟不补就白练”**：全天蛋白质总量更重要，窗口期没那么窄。
2. **“运动饮料日常喝”**：含糖，非运动场景容易增加热量。
3. **“蛋白质越多越好”**：超过需求会被氧化或储存，不额外增肌。
4. **“空腹训练更燃脂”**：可能影响高强度表现，长期减脂差异不大。
5. **“只补水不补盐”**：长时间大量出汗可能稀释性低钠。

## 实操建议

1. 练前 2 小时吃一顿正常餐，或 1 小时前吃香蕉 + 酸奶。
2. 训练 60 分钟内只喝水，超过 90 分钟准备碳水补给。
3. 练后一餐保证 20~40 克蛋白质 + 一份主食。
4. 运动前后称体重，按损失量补液。
5. 比赛日只吃平时训练验证过的食物。
