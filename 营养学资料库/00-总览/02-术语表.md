# 术语表

按主题分组。解释以"能看懂文章"为目标，不追求教科书式完整定义。

## 基础概念

| 术语 | 英文 / 缩写 | 一句话解释 |
|---|---|---|
| 营养素 | Nutrient | 食物中能被人体利用、维持生命和健康的物质。 |
| 必需营养素 | Essential nutrient | 人体不能合成或合成不足，必须从食物获得的营养素。 |
| 宏量营养素 | Macronutrient | 需要量以克计的蛋白质、碳水、脂肪，也常把水和膳食纤维算入。 |
| 微量营养素 | Micronutrient | 需要量以毫克或微克计的维生素和矿物质。 |
| 营养密度 | Nutrient density | 单位热量里有益营养素的含量，越高越"划算"。 |
| 能量密度 | Energy density | 单位重量食物的热量，越低越容易吃饱又不超量。 |
| 千卡 | kcal | 食物能量常用单位，1 千卡约等于 4.184 千焦。 |
| 千焦 | kJ | 中国食品标签的法定能量单位，除以 4.184 得千卡。 |

## 能量代谢

| 术语 | 英文 / 缩写 | 一句话解释 |
|---|---|---|
| 基础代谢率 | BMR | 清醒、静卧、空腹状态下维持生命所需的最低能量。 |
| 静息能量消耗 | REE | 接近基础代谢，测量条件更宽松，日常估算常用。 |
| 总能量消耗 | TDEE | 一天消耗的全部热量，约等于 BMR + TEF + NEAT + EAT。 |
| 食物热效应 | TEF | 消化吸收食物本身消耗的能量，约占摄入热量的 10%。 |
| 非运动性活动消耗 | NEAT | 走路、站立、家务等非刻意运动的消耗，个体差异很大。 |
| 运动性活动消耗 | EAT | 刻意运动训练消耗的能量。 |
| 代谢适应 | Metabolic adaptation | 长期热量缺口后，身体降低消耗、提高食欲的补偿反应。 |

## 需求与标准

| 术语 | 英文 / 缩写 | 一句话解释 |
|---|---|---|
| 膳食营养素参考摄入量 | DRIs | 一组营养素摄入标准的统称，包含 EAR、RNI、AI、UL 等。 |
| 平均需要量 | EAR | 满足某一人群 50% 个体需要的摄入量。 |
| 推荐摄入量 | RNI | 满足绝大多数（约 97%~98%）个体需要的摄入量。 |
| 适宜摄入量 | AI | 缺乏足够数据时，基于观察设定的摄入量。 |
| 可耐受最高摄入量 | UL | 长期每日摄入不应超过的上限，超过风险增加。 |
| 宏量营养素可接受范围 | AMDR | 三大产能营养素占总热量的合理比例范围。 |

## 蛋白质

| 术语 | 英文 / 缩写 | 一句话解释 |
|---|---|---|
| 必需氨基酸 | EAA | 人体不能合成、必须从食物获得的 9 种氨基酸。 |
| 限制性氨基酸 | Limiting amino acid | 某种食物中含量最低、限制整体蛋白质利用的氨基酸。 |
| 优质蛋白 | High-quality protein | 氨基酸模式接近人体、消化吸收率高的蛋白质。 |
| 蛋白质消化率校正氨基酸评分 | PDCAAS | 评价蛋白质质量的经典指标，最高为 1.0。 |
| 可消化必需氨基酸评分 | DIAAS | 更新的蛋白质质量评价方法，比 PDCAAS 更精细。 |

## 碳水与纤维

| 术语 | 英文 / 缩写 | 一句话解释 |
|---|---|---|
| 血糖生成指数 | GI | 含 50 克可利用碳水食物升血糖的速度，以葡萄糖为 100。 |
| 血糖负荷 | GL | GI 乘以该份食物可利用碳水克数再除以 100，更贴近实际影响。 |
| 添加糖 | Added sugar | 加工或制备过程中额外加入的糖，不包括食物天然含糖。 |
| 游离糖 | Free sugars | 添加糖 + 蜂蜜、糖浆、果汁中的糖，WHO 建议限制的对象。 |
| 膳食纤维 | Dietary fiber | 不能被人体小肠消化吸收的碳水化合物，分可溶与不可溶。 |
| 益生元 | Prebiotic | 能被肠道有益菌选择性利用、带来健康益处的底物。 |

## 脂类

| 术语 | 英文 / 缩写 | 一句话解释 |
|---|---|---|
| 饱和脂肪酸 | SFA | 碳链无双重键，主要来自动物脂肪和部分植物油，过量不利血脂。 |
| 单不饱和脂肪酸 | MUFA | 含一个双键，橄榄油、茶籽油、牛油果中较多。 |
| 多不饱和脂肪酸 | PUFA | 含两个以上双键，包括 omega-3 和 omega-6。 |
| 反式脂肪酸 | TFA | 部分氢化油和高温精炼产生，升高 LDL、降低 HDL，应尽量避免。 |
| 必需脂肪酸 | EFA | 亚油酸和 α-亚麻酸，人体不能合成，必须从食物获得。 |
| Omega-3 | n-3 | 包括 ALA、EPA、DHA，深海鱼和亚麻籽是主要来源。 |

## 微量营养素

| 术语 | 英文 / 缩写 | 一句话解释 |
|---|---|---|
| 植物化学物 | Phytochemical | 植物中非必需但可能有健康作用的化合物，如多酚、类胡萝卜素。 |
| 生物利用度 | Bioavailability | 摄入的营养素被吸收并进入血液循环的比例。 |
| 强化食品 | Fortified food | 人为添加了某种或多种营养素的食品，如强化面粉、加碘盐。 |

## 食物与标签

| 术语 | 英文 / 缩写 | 一句话解释 |
|---|---|---|
| 超加工食品 | Ultra-processed food | NOVA 分类第四类，工业配方、含多种添加剂、几乎不含完整食物。 |
| 可食部 | Edible portion | 食物去掉皮、核、骨等不可食部分后的比例。 |
| 营养声称 | Nutrition claim | 如"高钙""低脂""无糖"，有法定含量条件，不能随便写。 |
| 功能声称 | Function claim | 声称某种成分对生理功能有益，监管比营养声称更严。 |
| 蓝帽子 | — | 中国保健食品专用标志，代表经过注册或备案。 |

## 体重与体成分

| 术语 | 英文 / 缩写 | 一句话解释 |
|---|---|---|
| 体质指数 | BMI | 体重（kg）除以身高（m）的平方，用于粗略判断体重状态。 |
| 腰臀比 | WHR | 腰围除以臀围，反映腹部脂肪分布。 |
| 体脂率 | Body fat percentage | 脂肪重量占体重的比例，比体重更能反映胖瘦。 |
| 体重循环 | Weight cycling | 反复减重又反弹的"溜溜球"模式，可能影响代谢与心理。 |

## 临床与评估

| 术语 | 英文 / 缩写 | 一句话解释 |
|---|---|---|
| 医学营养治疗 | MNT | 由专业人员实施的、针对疾病的营养干预方案。 |
| 营养诊断 | Nutrition diagnosis | 对营养问题的规范化表述，是制定干预方案的依据。 |
| 肠内营养 | EN | 通过口服或管饲提供营养，优先于肠外营养。 |
| 肠外营养 | PN | 通过静脉提供营养，用于肠道无法使用或不足时。 |
| 肌少症 | Sarcopenia | 随年龄或疾病出现的骨骼肌量、力量或功能下降。 |
| 恶病质 | Cachexia | 疾病相关的进行性体重下降和肌肉消耗，常见于肿瘤。 |
| 胰岛素抵抗 | Insulin resistance | 细胞对胰岛素反应下降，代偿性胰岛素升高，与 2 型糖尿病相关。 |
| 糖化血红蛋白 | HbA1c | 反映近 2~3 个月平均血糖水平的指标。 |

## 研究方法

| 术语 | 英文 / 缩写 | 一句话解释 |
|---|---|---|
| 随机对照试验 | RCT | 随机分组、控制变量，是判断因果关系的核心设计。 |
| 队列研究 | Cohort study | 长期追踪一群人，观察暴露与结局的关联，不能直接证明因果。 |
| 系统评价 | Systematic review | 按预设方法系统检索、筛选、汇总全部相关研究。 |
| Meta 分析 | Meta-analysis | 用统计方法合并多个研究结果，提高把握度。 |
| GRADE | GRADE | 对证据质量和推荐强度进行分级的国际通用体系。 |
| 混杂因素 | Confounder | 同时影响暴露和结局的第三变量，是观察性研究的主要干扰。 |
| 剂量-反应关系 | Dose-response | 暴露量增加、结局风险随之变化，是支持因果的重要线索。 |

## 使用提示

1. 看到"专家说"先找原始研究，再看研究类型和样本量
2. 看到"某食物致癌/治病"先问剂量、对象和证据等级
3. 术语解释用于理解文章，不替代临床诊断和个体化建议
