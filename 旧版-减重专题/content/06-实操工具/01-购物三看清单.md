# 购物三看清单

## ✅ 第一看：配料表前三位

- [ ] 第一位是主料本身（生牛乳 / 全麦粉 / 燕麦 / 生羊乳 / 大豆）
- [ ] 没有麦芽糊精、白砂糖、植脂末、植物油排在前三位
- [ ] 配料表越短越好，不认识的添加剂越少越好

## ✅ 第二看：营养成分表

- [ ] 调制乳粉：蛋白质 ≥ 18g/100g，钙 ≥ 800mg/100g
- [ ] 饼干：脂肪 ≤ 15g/100g
- [ ] 果蔬脆片：碳水化合物 ≤ 15g/100g
- [ ] 注意标注是"每 100 克"还是"每份"
- [ ] 钠 ≤ 600mg/100g 更理想

## ✅ 第三看：执行标准

- [ ] 纯牛奶认准 GB 19645（巴氏）或 GB 25190（灭菌）
- [ ] 乳粉认准 GB 19644
- [ ] 看到 GB/T 29602（固体饮料）不要当奶粉买

## 购物车红黑榜

| 多拿 | 少拿 |
|---|---|
| 纯牛奶、无糖酸奶 | 乳酸菌饮料、含乳饮料 |
| 纯燕麦片、全麦粉 | 花式麦片、粗粮饼干 |
| 鸡蛋、去皮鸡腿、鱼虾 | 鸡爪、猪蹄、鸡皮 |
| 新鲜蔬菜、整果 | 果蔬脆片、果汁 |
| 豆腐、豆制品 | 素肉、豆干零食 |
| 原味坚果（小包装） | 盐焗、糖衣坚果 |

## 结账前 30 秒

1. 手上有没有"包装上写着健康、配料表第一位是糖或水"的东西？
2. 有没有"无蔗糖"但碳水很高的东西？
3. 有没有把固体饮料当奶粉？
