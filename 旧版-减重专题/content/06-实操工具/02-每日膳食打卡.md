# 每日膳食打卡清单

> 来自《中国居民膳食指南（2022）》口径，可按个人热量目标微调。

## 今日打卡

- [ ] 奶及奶制品 300~500ml
- [ ] 鸡蛋 1 个（不弃蛋黄）
- [ ] 鱼禽瘦肉 掌心大小 2~3 份
- [ ] 大豆及坚果 25~35g
- [ ] 蔬菜 300~500g（深色占一半）
- [ ] 新鲜水果 200~350g（整果，不打汁）
- [ ] 主食 250~400g，其中全谷物杂豆占 1/3
- [ ] 饮水 1500~1700ml
- [ ] 日照 15~20 分钟
- [ ] 每日 12 种以上食物，每周 25 种以上

## 减重期附加打卡

- [ ] 烹调油 ≤ 20~25g
- [ ] 盐 ≤ 5g
- [ ] 步数 ≥ 6000~8000 步
- [ ] 睡前 3 小时不进食
- [ ] 睡眠 7 小时以上

## 使用建议

- 先连续打卡 7 天，找出最容易缺的那一项
- 不要追求 100% 完成，完成 80% 就能带来变化
- 把清单设成手机壁纸或放在冰箱上
