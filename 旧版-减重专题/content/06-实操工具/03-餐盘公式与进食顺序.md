# 餐盘公式与进食顺序

## 一拳两拳法（不用称重）

| 部分 | 份量 | 内容 |
|---|---|---|
| 蛋白质 | 一掌心 | 鱼虾、去皮禽肉、瘦牛肉、豆腐、蛋 |
| 蔬菜 | 两拳 | 深色叶菜、菌菇、瓜类、海带 |
| 主食 | 一拳 | 杂粮饭、薯类、玉米、燕麦 |

> 公式：**优质蛋白 + 两拳低卡蔬菜 + 一拳杂粮或薯类。**

## 进食顺序

1. **先喝清汤 / 吃蔬菜**：占位，降低正餐摄入
2. **再吃蛋白质**：延缓胃排空，稳住血糖
3. **最后吃主食**：此时饥饿感已下降，自然吃少
4. **细嚼慢咽**：每口咀嚼 15~20 次，一餐至少 20 分钟

## 餐前置换

饭前先喝一碗清汤或吃一大盘少油蔬菜，正餐自然少吃。

- 有研究提到，餐前一碗清汤能减少正餐摄入约 **20%**
- 汤要清汤，不要奶白浓汤和重盐汤
- 是"置换"不是"叠加"

## 外食场景

| 场景 | 点法 |
|---|---|
| 火锅 | 清汤锅底、先涮菜和肉、少蘸料、不喝汤底 |
| 烧烤 | 选瘦肉和蔬菜、去皮、少刷酱 |
| 快餐 | 主食减半、加一份蔬菜、饮料换无糖 |
| 面馆 | 加青菜和牛肉、少喝汤、面减半 |
| 聚餐 | 先吃菜、慢喝酒、主食最后少量 |

## 一周落地节奏

- 第 1 周：只练进食顺序
- 第 2 周：加上餐盘比例
- 第 3 周：控制烹调油和盐
- 第 4 周：复盘体重、腰围和依从性
