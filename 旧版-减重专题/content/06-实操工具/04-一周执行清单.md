# 一周执行清单

## Day 1：清点与清理

- [ ] 清掉/收走高糖饮料、糕点、薯片
- [ ] 量一次体重、腰围，拍照记录
- [ ] 定一个 4 周目标（每周 0.5~1 公斤）

## Day 2：采购

- [ ] 按[购物三看清单](01-购物三看清单.md)买齐一周食材
- [ ] 蛋白质：鸡蛋、去皮鸡腿、鱼虾、豆腐、无糖酸奶
- [ ] 主食：燕麦、糙米、红薯、玉米
- [ ] 蔬菜：深色叶菜、菌菇、瓜类
- [ ] 水果：苹果、柚子、莓类

## Day 3：备餐

- [ ] 杂粮饭一次煮好，分装冷冻
- [ ] 鸡腿去皮分装，腌好冷藏
- [ ] 蔬菜洗好沥干，3 天内吃完
- [ ] 煮一锅清汤，分份冷冻

## Day 4~6：执行

- [ ] 每餐按"两拳蔬菜 + 一掌心蛋白 + 一拳主食"
- [ ] 先菜 → 再肉 → 最后主食
- [ ] 每天 1500~2000ml 水
- [ ] 每周 150 分钟运动，拆成每天 20~30 分钟
- [ ] 睡眠 7 小时以上

## 外食与应酬预案

1. 赴宴前先吃一份蔬菜或一杯无糖酸奶
2. 优先夹清蒸、白灼、炖菜，避开油炸和勾芡
3. 酒尽量不喝，喝了就当天减少主食
4. 第二天正常吃，不要用断食"惩罚"自己

## 平台期怎么办

- 连续 2~3 周体重不动才叫平台期，先排除水分波动
- 检查是否"隐形摄入"：酱料、坚果、饮料、试吃
- 增加日常活动量，或调整运动类型
- 不要继续压低热量，先保证蛋白质和睡眠
