# 一天搭配示例（约 1300~1500 千卡）

> 适合中小体型成年人的减重期参考，具体份量需按身高体重、活动量和目标调整。

## 三餐安排

| 餐次 | 内容 |
|---|---|
| 早餐 | 50 克燕麦煮粥 + 1~2 个鸡蛋 + 无糖酸奶或牛奶 |
| 午餐 | 一小碗杂粮饭（生重 50~75 克）+ 掌心大小的鸡胸肉或鱼虾 + 一大盘青菜 |
| 加餐 | 一个苹果，或一小把原味坚果（10~15 克） |
| 晚餐 | 红薯或玉米代替主食 + 豆腐或虾 + 蔬菜汤，17:00~19:00 吃完 |

## 执行要点

- 蔬菜每天 300~500 克，深色占一半
- 烹调油每天 20~25 克，盐不超过 5 克
- 饮水 1500~2000 毫升，不要用含糖饮料代替
- 晚餐尽量在 19:00 前完成，避免夜宵
- 饿了先加蔬菜或蛋白质，不要硬扛到暴食

## 同类替换（避免吃腻）

| 原食材 | 可替换 |
|---|---|
| 燕麦 | 全麦面包、玉米、红薯 |
| 鸡胸肉 | 去皮鸡腿、鱼虾、瘦牛肉、豆腐 |
| 杂粮饭 | 藜麦、糙米、荞麦面 |
| 无糖酸奶 | 纯牛奶、无糖豆浆 |
| 苹果 | 梨、柚子、草莓、蓝莓（约 200 克） |

## 外食怎么点

1. 优先蒸、煮、炖、白灼，避开油炸、干锅、红烧
2. 主食减半，先吃蔬菜和蛋白质
3. 酱料分开装，蘸着吃
4. 饮料选无糖茶或白水
