# 误区 9-10：给父母的饮食提醒

## 误区 9：给父母的两个反向提醒

### 别让老人少吃肉

- 长期不吃动物性食物会导致贫血、低体重、肌肉过快丢失
- 老人蛋白质应按**每公斤体重 1.0~1.2 克**摄入
- 举例：60 公斤老人每天约需 60~72 克蛋白质
- 优先易咀嚼的鱼虾、去皮禽肉、蛋、奶、豆腐

### 食物不必越软烂越好

- 适当咀嚼有助于延缓脑功能衰退
- 长期只吃糊状食物，咀嚼肌和消化功能都可能退化
- 在牙口允许的范围内保留一定口感

## 误区 10：老人只喝白粥、只吃蔬菜"清淡饮食"

真正的清淡饮食是**营养全面充足、不刺激、好消化**，而非只吃白粥咸菜。

清淡 = 少油少盐少糖少刺激 + 营养均衡，优先蒸、煮、烩的烹饪方式。

### 老人一日饮食框架

| 项目 | 建议 |
|---|---|
| 奶及奶制品 | 300~500 毫升 |
| 鸡蛋 | 1 个，不弃蛋黄 |
| 鱼禽瘦肉 | 每餐掌心大小，尽量软嫩 |
| 大豆及坚果 | 25~35 克 |
| 蔬菜 | 300~500 克，深色占一半 |
| 水果 | 200~350 克，选软质整果 |
| 主食 | 粗细搭配，粗粮 50~100 克 |
| 饮水 | 1500~1700 毫升，少量多次 |

> 老人味觉退化容易重口味，用葱姜蒜、醋、柠檬提味，减少盐和酱油。
