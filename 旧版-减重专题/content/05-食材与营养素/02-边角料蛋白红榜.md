# 边角料蛋白红榜：便宜又优质的部位

"边角料"指那些便宜、容易被忽略的部位与副产品——鸡爪、鸡架、内脏、动物血、豆渣之类。这里面有好东西也有坑，差别非常大。

## 值得吃的廉价好蛋白

| 食材 | 热量（每 100 克） | 亮点 |
|---|---|---|
| 鸭血 / 猪血 | 约 55 千卡 | 蛋白高、脂肪极低、补铁 |
| 鸭胗 | 约 92 千卡 | 蛋白约 19 克，脂肪低 |
| 牛肚 | 约 97 千卡 | 脂肪仅约 1.6 克 |
| 猪肝 | 约 130 千卡 | 蛋白约 20 克、脂肪约 3.5 克，补铁补维生素 A |
| 去皮鸡腿肉 | 约 130~150 千卡 | 比鸡胸便宜还嫩，性价比之王 |
| 去皮鸭胸 | 约 115~130 千卡 | 蛋白约 20 克，含铁高 |

## 两条实操建议

1. 想省钱补蛋白，首选**鸡蛋 + 去皮鸡腿肉 + 鸭血或猪血 + 豆腐 + 豆渣**，比鸡胸便宜，营养不打折
2. 边角料最大的雷是做法：卤味、红烧、烧烤会加入大量油糖盐，把低脂食材做成热量炸弹。清炖、水煮、凉拌才划算

## 推荐做法

| 食材 | 低油做法 |
|---|---|
| 鸭血/猪血 | 血豆腐汤、韭菜炒血豆腐（少油） |
| 鸭胗 | 白灼后凉拌、卤制后去皮少蘸汁 |
| 牛肚 | 清炖萝卜牛肚、凉拌 |
| 猪肝 | 快炒或汆汤，每周 1~2 次、每次 50~100 克 |
| 去皮鸡腿 | 去皮后烤、炖、白切 |
| 去皮鸭胸 | 低温煎、烤，切片拌沙拉 |
