# 营养素与食物来源对照

| 营养素 | 每日推荐量 | 最划算的食物来源 |
|---|---|---|
| 钙 | 成人 800mg；50 岁以上 1000mg | 牛奶/酸奶 300~500ml、北豆腐、焯水绿叶菜、芝麻酱、带骨小鱼 |
| 蛋白质 | 男 65g / 女 55g；65 岁以上 72g / 62g（约 1.0~1.2g/kg） | 1 个蛋 + 1 杯奶 + 掌心大鱼禽肉 + 豆制品，分三餐摄入 |
| 铁 | 按需，先查血常规 | 动物血、猪肝（每周 1~2 次，每次约 50g）、红肉，搭配维生素 C |
| 维生素 D | 成人 400IU | 日照 15~20 分钟 + 深海鱼/蛋黄；老人多需直接补充制剂 |
| 膳食纤维 | 25~30g | 全谷物杂豆占主食 1/3、整果不打汁 |
| Omega-3 | 每周吃鱼 2 次 | 三文鱼、鲭鱼、沙丁鱼；核桃、亚麻籽油仅作辅助 |

## 补钙细节提示

- 一次补钙不超过 500mg 吸收最佳，建议分次补充
- 避免与高纤维、高草酸食物同食
- 钙需与维生素 D 同补，维 D 是"搬运工"
- 低盐饮食（盐摄入过多会增加钙流失）

## 蛋白质怎么分配到三餐

| 餐次 | 示例 |
|---|---|
| 早餐 | 1 个鸡蛋 + 1 杯牛奶/无糖酸奶 |
| 午餐 | 掌心大小鱼禽瘦肉 + 豆腐 |
| 晚餐 | 虾/鱼/豆制品，清淡烹饪 |

## 铁的吸收技巧

- 动物性铁（血红素铁）吸收率 15%~35%，远高于植物铁
- 搭配维生素 C（彩椒、猕猴桃、橙子）可促进非血红素铁吸收
- 茶、咖啡中的单宁会抑制铁吸收，建议与正餐错开
