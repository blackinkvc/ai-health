# 知识库怎么用

本站内容来自两份原始资料，按"先建立正确认知 → 再识别陷阱 → 最后落地执行"的顺序重组。

## 六个分类

| 分类 | 回答什么问题 | 适合谁 |
|---|---|---|
| 01 入门总览 | 减脂的底层逻辑是什么 | 第一次接触，先看这里 |
| 02 减重原理与吃法 | 具体怎么吃、吃多少、怎么搭配 | 正在减重的人 |
| 03 食物陷阱鉴别 | 哪些"健康食品"其实是智商税 | 常买营养品、看直播囤货的人 |
| 04 日常营养误区 | 喝汤、蛋黄、粗粮、隔夜菜等常见困惑 | 家庭做饭的人 |
| 05 食材与营养素 | 补钙补铁补蛋白到底吃什么 | 想精准补营养的人 |
| 06 实操工具 | 购物、打卡、餐盘公式 | 需要马上照做的人 |

## 推荐阅读路径

1. **快速入门**：核心结论 → 三条底层原则 → 减脂的唯一通路 → 每日膳食打卡
2. **避坑优先**：伪营养品排行榜 → 配料表与执行标准 → 伪粗粮与伪乳饮
3. **给父母看**：喝汤弃肉与丢掉蛋黄 → 粗粮过量与脱脂奶迷信 → 老年人的两个饮食提醒
4. **采购清单**：购物三看清单 → 边角料蛋白红榜 → 边角料蛋白黑榜
