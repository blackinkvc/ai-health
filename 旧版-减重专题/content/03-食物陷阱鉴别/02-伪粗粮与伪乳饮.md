# 伪粗粮与伪乳饮

## 伪粗粮系列

| 产品 | 真相 |
|---|---|
| 粗粮饼干 | 为改善粗糙口感，油脂常高达 30% 以上，含糖可达 30g/100g |
| 花式麦片 | 实为"糖渍果干 + 喷油烘烤谷物"，每 100g 含糖 15~25g，部分含植脂末 |
| 罐装八宝粥 | 某品牌 375g 一罐含糖约 31g，直接超全天建议量（25g） |
| 全麦面包 | 配料表第一位常是精制小麦粉，而非全麦粉 |
| 果蔬脆片 | 多数为真空低温油炸（VF），脂肪含量 10%~40%；冻干（FD）工艺相对较好 |

### 怎么选真粗粮

1. 全麦面包：配料表第一位必须是"全麦粉"，且占比越高越好
2. 燕麦：选配料表只有"燕麦"的纯燕麦片，避开"麦片 + 糖 + 植脂末"
3. 饼干：脂肪 ≤ 15g/100g 才算相对可以，粗粮饼干大多不达标
4. 八宝粥：自己煮，不加糖，控制份量

## 伪乳饮系列

- **常温乳酸菌饮料**：经灭菌处理，基本无活菌；含糖量普遍 15g/100ml 以上（养乐多 17.6g/100g，高于可乐的 10.6g）
- **核桃奶 / 燕麦奶等含乳饮料**：配料表第一位常常是水，蛋白质远低于纯牛奶

### 怎么选真奶

| 类型 | 执行标准 | 说明 |
|---|---|---|
| 巴氏杀菌乳 | GB 19645 | 纯牛奶，需冷藏 |
| 灭菌乳 | GB 25190 | 纯牛奶，常温保存 |
| 调制乳 | GB 25191 | 牛奶含量 80% 以上 |
| 调制乳粉 | GB 19644 | 正规乳粉 |
| 固体饮料 | GB/T 29602 | 蛋白质和钙都低一大截，别当奶粉买 |

## 一句话判断

**配料表第一位是水、白砂糖、精制小麦粉的，都不是它包装上暗示的那个东西。**
